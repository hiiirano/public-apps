## 1. 目的
毎日の「今日の晩ごはん、何にしよう」をなくす。**家族の条件を選ぶだけで、1週間分の夕食（主菜・副菜・汁物）と買い物リストが1画面で眺められる**ようにする。料理の絵を大きく出し、見ていて楽しい画面にする。

### 1.1 想定する場面
- 日曜の夜、スマホで来週の夕食を決めて、そのままスーパーへ。大人2人・子ども1人、子どもは卵アレルギー、夫は牛肉とネギが苦手、冷蔵庫にキャベツとリンゴが残っている。
- 「和食が多めがいいけど、毎日和食だと飽きる」。
- 月曜の献立だけ気に入らないので、その日だけ変えたい。

### 1.2 やらないこと
| やらないこと | 理由・今後の案 |
|---|---|
| 朝食・昼食の献立 | 料理データ149品は夕食向けの主菜・副菜・汁物だけで、朝食向き（パン・ご飯のお供・卵料理の小皿など）や弁当向きのデータがない。少ないデータで出すと毎日同じになり、品質を保てない。**今後の案**: 朝食30品・昼食（麺・丼・弁当）30品を足したうえで、日ごとの「朝・昼・晩」の開閉を足す（画面は日ごとに「夕食」を開閉できる形にしてあり、そのまま増やせる） |
| 作り方（手順）の表示 | 手順のデータがない。調べ直しと監修が要る。今後の案: 主な20品から手順を付ける |
| 栄養計算（カロリー・塩分） | 数値の根拠となるデータがない |
| 9品目以外のアレルギーの専用判定 | 9品目（卵・乳・小麦・そば・落花生・えび・かに・大豆・くるみ）だけを判定。ほかは「苦手なもの」に材料名を入れて外す |
| 「和食だけ」にする設定 | 利用者から「全部和食になる」と指摘があったため、ジャンルは「多め」だけにした（§8 で確認） |
| AI・外部 API・会員登録・サーバー保存 | 端末の中だけで完結させる |

## 2. 利用者
| 利用者 | 特徴 | 求めること |
|---|---|---|
| 献立を決める人（主） | ITに詳しくない。スマホで、買い物前や家事の合間に使う | 迷わず選べる。ボタンで選べる。結果がすぐ見える |
| 家族（従） | LINE で献立・買い物リストを受け取る | 何を作るか、何を買うかが一目で分かる |

## 3. 機能要件

### F1 人数
- F1-1 大人 1〜10人（初期値2）、子ども 0〜10人（初期値1）。「−」「＋」で変える。
- F1-2 子どもは大人の半分の量で計算する。

### F2 ジャンル（利用者の指摘3）
- F2-1 「おまかせ」「和食多め」「洋食多め」「中華多め」から1つ選ぶ。初期値はおまかせ。
- F2-2 おまかせは7日のうち 3日・2日・2日。「多め」は選んだジャンルを4日、残りの2ジャンルを2日と1日にする。**1つのジャンルだけにはしない**。
- F2-3 同じジャンルが3日続かないように並べる。
- F2-4 選び方の説明（「和食を7日のうち4日、洋食と中華を合わせて3日にします」）を選択欄の下に出す。
- F2-5 条件に合う料理が足りず4日にできないときは、その旨を表示する。

### F3 アレルギー（安全側）
- F3-1 9品目を選んで外す。選んだ品目を**少しでも含む疑いのある料理**（しょうゆの小麦・大豆、ハムの卵・乳など加工品を含む）はすべて外す。
- F3-2 アレルギーの条件は、候補が足りなくても**絶対にゆるめない**。
- F3-3 商品ごとに原材料が違うこと、買うときに表示を確かめることを、選択欄の下に書く。

### F4 苦手なもの（利用者の指摘1）
- F4-1 よくある苦手食材16種をボタンで選ぶ（牛肉・豚肉・鶏肉・魚・えび・かに・いか・貝・ねぎ・玉ねぎ・きのこ・なす・ピーマン・トマト・にんじん・辛いもの）。
- F4-2 自由入力も残す（「、」や空白で区切って複数可。Enter または「追加」）。
- F4-3 言葉は**分類と言い換え辞書**で材料名にそろえて判定する（部分一致はしない）。
  - 分類: 牛肉＝牛こま切れ肉・合いびき肉／豚肉＝豚肉4種・合いびき肉・ハム・ベーコン・ウインナー／鶏肉／ひき肉／魚／青魚／えび／かに（かにかま含む）／いか／貝／魚介／ねぎ／玉ねぎ／きのこ／豆腐／乳製品／辛いもの／ごま など
  - 表記ゆれ: ひらがな・カタカナ・漢字・半角・全角（ネギ／葱／ねぎ、人参／ニンジン、ｷｬﾍﾞﾂ など）
  - **ねぎ**（長ねぎ・青ねぎ・万能ねぎ・小ねぎ・九条ねぎ）と**玉ねぎ**は別のものとして扱う。ねぎを選ぶと「玉ねぎは外れません」と出す。料理データのねぎは「長ねぎ」1種類なので、青ねぎ等も長ねぎとして扱う。
  - 辞書に無い言葉は、材料名の一部（2文字以上）で探し、それでも無ければ料理名で外す（例「カレー」）。
- F4-4 選んだ言葉ごとに「何を使う何品を外すか」を表示する。

### F5 冷蔵庫の残り（利用者の指摘2）
- F5-1 よく残る食材12種をボタンで、ほかは自由入力で入れる。F4-3 と同じ辞書で照合する。
- F5-2 残り物を使う料理を優先して選ぶ（まだ使っていない残り物を使う料理を強く優先し、1回使えたら優先をやめる）。
- F5-3 残り物ごとに「何曜日の何で使うか」を表示する。料理データに無いもの（例: リンゴ）は「この献立の料理では使いません」、ほかの条件で外れたものは「使う料理がほかの条件で外れています」と出す。
- F5-4 料理の札に「残り物：キャベツ」、買い物リストに「家にある」を付ける。

### F6 1日の夕食（利用者の指摘4）
- F6-1 毎日「主菜＋副菜＋汁物」。副菜・汁物はそれぞれ付けない設定もできる（初期値は付ける）。
- F6-2 ラーメン・うどんなど汁のある麺の日は汁物を付けない。
- F6-3 副菜・汁物は、主菜と同じジャンルを優先し、主菜と同じ材料（豆腐と冷奴など）や卵料理の重なりを避ける。
- F6-4 週の中で同じ主菜・副菜・汁物をなるべく重ねない（候補が足りないときは重ね、主菜が重なったら知らせる）。
- F6-5 「20分以内の料理だけ」を選べる。

### F7 1週間の表示（利用者の提案5）
- F7-1 上に7日分のジャンル（色）と主菜の絵を並べた帯と、ジャンルごとの日数・20分以内の日数・残り物の使用数を出す。
- F7-2 日ごとの札に、主菜の絵（大）・副菜と汁物の絵、各料理の時間を出す。
- F7-3 日ごとの「夕食」を開閉できる。閉じても絵と主菜名が見える。「すべて閉じる／すべて開く」。
- F7-4 日ごとに「この日を変える」で、その日だけ別の組み合わせ（同じジャンル・ほかの日と重ならない）にする。
- F7-5 「別の組み合わせ」で週全体を作り直す。
- F7-6 材料（人数分の量）と9品目のアレルギーを日ごとに開いて見られる。

### F8 買い物リスト
- F8-1 7日分の材料を人数分に換算し、同じ材料をまとめ、売り場の順（野菜→肉・魚→乳・卵→主食→その他）に並べる。調味料は畳んで別に出す。
- F8-2 量は足りなくならないよう切り上げて切りのよい数にする（例 187.5g→190g、卵 11.5個→12個）。
- F8-3 買ったものにチェックを付けられる。「何品中何品買ったか」を出す。
- F8-4 「買い物リストをコピー」「献立をコピー」（LINE に貼れる文）。コピーできない端末では選んでコピーできる欄を出す。

### F9 保存と再開
- F9-1 条件・「この日を変える」の回数・買ったチェックを端末に保存し、次に開いたとき同じ献立を出す。
- F9-2 前の版の保存（`meal-planner.input`）から人数・アレルギー・苦手・残り物を引き継ぐ。アレルギーは必ず引き継ぐ。
- F9-3 保存できない環境でも献立は作れる（その旨を表示）。

### F10 オフライン
- F10-1 一度開いた端末では、電波がなくても開いて献立を作り直せる（料理の絵も出る）。
- F10-2 ホーム画面に追加でき、アプリのアイコンが出る。

## 4. 非機能要件
| 区分 | 要件 |
|---|---|
| 対応環境 | iOS Safari 16以上、Android Chrome 最新、PC の Chrome / Safari / Edge 最新 |
| 画面幅 | 320px〜1440px で崩れない。主は 390px。PC（1100px〜）は左に条件、右に献立 |
| 速さ | 操作の反映 0.1秒以内（献立の作り直しは端末内で数ミリ秒） |
| 使いやすさ | 押せるものは 44×44px 以上、入力欄の文字は 16px 以上、本文 16px 以上。条件はボタンで選べる |
| アクセシビリティ | WCAG 2.2 AA。コントラスト 4.5:1 以上。キーボードだけで全操作可能 |
| 個人情報 | 入力は端末内だけに保存。外部への通信 0 件。アクセス解析なし |
| 安全 | 入力した言葉は無害化して表示。外部スクリプトなし。公開版は CSP で外部接続を禁止 |
| 正しさ | アレルギー・苦手・時短は必ず守る（ランダム3,000通りで検査）。同じ条件なら同じ献立 |
| 見た目 | 緑系。料理の絵を大きく。ダークモード対応 |

## 5. 受け入れ基準
| No | 確認すること | 合格の条件 |
|---|---|---|
| AC-01 | 初めての人が使える | 説明なしで、場面1.1の1つ目を **90秒以内** に、条件を入れて買い物リストのコピーまでできる（3人で確認） |
| AC-02 | 苦手なもの | 「牛肉」で牛こま切れ肉・合いびき肉の料理、「ネギ」で長ねぎの料理が1品も出ない。玉ねぎの料理は残る |
| AC-03 | 残り物 | 「キャベツ・リンゴ・ネギ」でキャベツと長ねぎを使う料理が入り、どの日に使うかが出る。リンゴは使わないと出る |
| AC-04 | ジャンル | 「和食多め」で和食4日・洋食と中華が合わせて3日（ランダム200通りで確認） |
| AC-05 | 品数 | 毎日 主菜＋副菜＋汁物（汁のある麺の日は汁物なし） |
| AC-06 | アレルギー | 9品目のどの組み合わせでも、含む疑いのある料理が出ない（ランダム3,000通り） |
| AC-07 | 開閉 | 日ごとに夕食を開閉でき、閉じても絵と料理名が見える |
| AC-08 | 端末 | iPhone 実機（Safari）と Android 実機（Chrome）で全操作ができる |
| AC-09 | オフライン | 機内モードで開いて献立を変えられる |
| AC-10 | アクセシビリティ | axe で違反 0 件 |
| AC-11 | 画面 | 320 / 390 / 768 / 1280px、ライト / ダークで崩れ・重なり・はみ出し 0 件 |
| AC-12 | 個人情報 | 外部への通信 0 件 |
