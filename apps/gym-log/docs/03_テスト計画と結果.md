### T2 で必ず成り立つこと
- 「＋」「−」の結果は 0〜500kg に収まり、刻みの倍数にそろい、「＋」は必ず増え「−」は必ず減り（端を除く）、1刻みより大きく動かない
- 全角で書いた数は、元の数として読める
- まとめの総重量 = 重さのある種目の量の合計。自己ベストの数 ≦ セット数
- 過去の記録は、その時点までの自己ベストを超えない。最高より重いセットは必ず自己ベスト
- 今週やっていれば続けた週は1以上。続けた週は記録のある週の数を超えない
- 保存して読み直すと同じ記録に戻る。途中で切れた保存内容でも落ちない

## 3. 見つかった不具合と対応

| No | 内容 | 見つけた検査 | 対応 |
|---|---|---|---|
| B1 | （前の版）種目名をそのまま画面に入れており、名前に HTML を入れると動いてしまう | 確認（コード） | すべて無害化して出す。T3 で確認 |
| B2 | （前の版）保存内容を検査せず、壊れていると画面が出ない | 確認（コード） | 形と範囲を検査し、合わなければ初期状態。T1・T3 で確認 |
| B3 | （前の版）削除や読み込みに確認ダイアログ（confirm/alert）を使い、片手で押しにくい | 確認（操作） | 「元に戻す」付きのお知らせと、画面内の2段階確認に変更 |
| B4 | 上限（500kg）を超えた数を入れて「−」を押すと、500 のまま減らない | T2 | 先に範囲に収めてから1刻み動かす |
| B5 | 320px で、記録中の帯に休けい時間が出ると横にはみ出す | T4 | 狭い画面では「記録中」の文字とセット数を省き、休けいは時計の絵＋時間に |
| B6 | 320px で、セットの行に「自己ベスト」の印が付くと横にはみ出す | T4 | 狭い画面では印を数字の下の行に回す |
| B7 | 設定の切り替えスイッチが 56×32px で小さい | T4 | 72×44px に |
| B8 | 390px で今週の総重量「2,090」が折り返す | T10 | 数字の大きさを画面幅に合わせ、折り返さない |
| B9 | PC で重さ・回数の欄が横に長すぎる | T10 | 600px 以上は重さと回数を横に並べる |
| B10 | まとめで「前回より −390kg」と減った数が出て、やる気をそぐ | T10 | 減った数は出さない |
| B11 | 記録は何回でも始められるのに、読み込みでは 5,000 回を超えると全体を初期状態にしていた。5,001 回目のあと開き直すと全履歴が消え、そのまま上書きされる（重大） | 外部レビュー（Codex） | 読み込みでは件数の上限を理由に捨てない（種目 200 も同じ）。始めるときに上限を検査し「記録は5,000回までです。設定から書き出して、古い記録を消してください」と知らせる。単体テスト3件・E2E 2件を追加 |

## 5. 利用者テストの手順（T9）
1. 相手に画面を渡し、「チェストプレスを、25kgで10回を2セット記録して、終わらせてください」とだけ伝える。
2. 画面を渡してから「おつかれさまでした」が出るまでの秒数を測る。説明や手助けはしない。
3. 終わったら「迷ったところ」を聞いて書き留める。
4. 合格は **3人とも 90 秒以内**（要件 AC-01）。
