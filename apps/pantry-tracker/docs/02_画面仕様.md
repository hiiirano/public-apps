# 在庫管理 — 画面仕様書

| 項目 | 内容 |

1画面と、入れる・直すためのダイアログ1つ。スマホ（〜999px）は縦1列、PC（1000px〜）は左に「そろそろ使う物」「買ってきた物を入れる」、右に「家にある物」と記録・データ。

## 1. 画面の並び
| 順 | 区画 | スマホ | PC |
|---|---|---|---|
| 0 | 上部（題・説明・今日の日付と急ぐ物の数） | 1列（600px〜 は横並び） | 横並び |
| 1 | そろそろ使う物 | ↓ | 左列 |
| 2 | 買ってきた物を入れる | ↓ | 左列 |
| 3 | 家にある物（冷蔵庫・冷凍庫・棚） | ↓（720px〜 は冷蔵庫を左、冷凍庫と棚を右） | 右列 |
| 4 | この30日の記録 | ↓ | 右列の下（720px〜 は記録とデータを横並び） |
| 5 | データ | ↓ | 同上 |
| — | お知らせ（入れた・取り消し・直す） | 画面下に8秒 | 同じ |
| — | 入れる・直すダイアログ | 画面中央 | 同じ |

## 2. 区画ごとの部品

### 上部
| 部品 | 仕様 |
|---|---|
| 今日の日付 | 「今日は 10/23（金）」。日付が変わると描き直す |
| 数の札 | 期限切れ（赤）・今日まで（濃いオレンジ）・2日以内（淡いオレンジ）。0 のときは灰色 |
| 合計 | 「家にある物 14 種類」 |

### そろそろ使う物
| 状態 | 表示 |
|---|---|
| 何もない | 「まだ何も入っていません。下の「買ってきた物を入れる」から始めましょう。」 |
| 急ぐ物がない | 「急いで使う物はありません。」 |
| ある | 1行ずつ: 絵・名前（×数）・置き場所・期限の札。行を押すと直すダイアログ。下に「使った」「捨てた」（44px）。左の太線を期限の色に。600〜999px は行の右にボタンを並べる |

### 買ってきた物を入れる
| 部品 | 仕様 |
|---|---|
| よく買う物のボタン | 絵・名前・置き場所（アイコン付き）。高さ 108px。最初は 12 種、押した回数が多い順 |
| ぜんぶ見る | 32 種に広げる／「少なく表示」で戻す（aria-expanded） |
| ほかの物を入れる | 入れるダイアログを開く |

### 家にある物
| 部品 | 仕様 |
|---|---|
| 冷蔵庫 | 白い箱・左上に取っ手・中は淡い青緑、物の下にガラスの棚板の線 |
| 冷凍庫 | 上に引き出しの取っ手・中は霜の青（点線の枠） |
| 棚 | 木の色の枠、物の下に木の板 |
| 食材の札 | 絵 52px・名前・期限の札・数（×2）。期限切れと今日までは枠に色。押すと直すダイアログ |
| 空 | 「まだ何もありません」「空っぽ」 |
| 床 | 区画の下端に木の床の帯 |

### 入れる・直すダイアログ
| 部品 | 仕様 |
|---|---|
| 見出し | 絵・名前（新しく入れるときは「ほかの物を入れる」）・閉じる（×） |
| 名前 | 20文字まで。空で入れようとすると「名前を入れてください。」 |
| 絵を選ぶ | 開閉式。32 種から選ぶ。選ぶまでは名前から自動で当てる |
| 置き場所 | 冷蔵庫・冷凍庫・棚の3択 |
| 数 | −・＋と直接入力（1〜99、全角数字も可） |
| 期限 | 日付欄、その下に札（「あと7日」と日付）。「今日」「3日後」「1週間後」「1か月後」「期限なし」 |
| 入れる／保存する | 幅いっぱい 56px |
| なくなったら記録（直すときだけ） | 「使い切った」「捨てた」（2つ以上なら「1つ使った」「1つ捨てた」）、「まちがえて入れた（記録せずに消す）」 |
| 閉じ方 | ×、Esc、外側を押す |

### この30日の記録
| 状態 | 表示 |
|---|---|
| 記録なし | 「「使った」「捨てた」を押すと、ここにまとまります。…」 |
| 記録あり | 使い切った数・捨てた数（大きな数字）、割合の帯（SVG、読み上げは文で）、「捨てた割合 20%」、買いすぎかも（淡いオレンジの枠）、捨てた物の一覧（捨てた／使った） |

### データ
| 部品 | 仕様 |
|---|---|
| 説明 | 端末の中にだけ残ること、機種変更のときの手順 |
| 書き出す | `pantry-YYYY-MM-DD.json` を保存 |
| 読み込む | ファイルを選ぶ。成功「読み込みました（n種類・記録n件）。」、失敗「このファイルは読み込めません。…」 |
| 見本を入れる | 何も入っていないときだけ出す |
| すべて消す | 入れた物と記録を消す（よく押す順は残す）。「元に戻す」付き |
| 保存できない環境 | 「この画面では保存できないため、閉じると内容が消えます（その場では使えます）。」 |

## 4. 保存する内容
localStorage のキー `pantry-tracker.v2` に、次を JSON で保存する。読み込み時に形と範囲（名前1〜20文字、数1〜99の整数、実在する日付、知っている絵・置き場所、id の重複なし、件数の上限）を検査し、合わなければ空の状態にする。

| 項目 | 中身 |
|---|---|
| items（300件まで） | id・名前・絵・置き場所・数・期限（日付か null）・入れた日 |
| log（2000件まで、古いものから消す） | id・名前・絵・使った／捨てた・数・日付 |
| freq | よく買う物を押した回数（名前ごと） |

書き出すファイルは同じ内容に `kind: "pantry-tracker"`・`version: 2`・`exportedOn` を付けたもの。
