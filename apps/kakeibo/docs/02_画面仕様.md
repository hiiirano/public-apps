# 家計簿ノート — 画面仕様書

| 項目 | 内容 |
|---|---|
| 版 | 1.0 |
| 作成日 | 2026-10-23 |
| 対応する要件 | 01_要件定義.md 1.0 |

1画面で完結する。スマホ（〜959px）は縦1列、PC（960px〜）は2列。

## 1. 画面の並び

| 順 | 区画 | スマホ | PC |
|---|---|---|---|
| 0 | 上部（ノートの絵・題・ひとこと・月の切り替え） | 縦 | 題と月の切り替えを横並び |
| 1 | 今月のペース | ↓ | 左列 上 |
| 2 | 書きこむ | ↓ | 右列 上 |
| 3 | 費目ごと | ↓ | 右列 |
| 4 | 記録（罫線のノート） | ↓ | 左列（下へのびる） |
| 5 | 予算とデータ | ↓ | 右列 |
| 6 | 下部（保存の説明・ほかのアプリ） | ↓ | 中央 |
| — | 画面下の「書きこむ」帯 | 書きこむ欄が画面に見えないときだけ | 出さない |
| — | お知らせ（元に戻す付き） | 画面下に 5〜8 秒 | 同じ |

売りである「ペース」を最初に、すぐ下に入力を置く。スマホで下へ送ったときは、帯の「書きこむ」で入力欄へ戻れる。

## 2. 区画ごとの部品

### 上部
| 部品 | 仕様 |
|---|---|
| 題 | 「家計簿ノート」（明朝）。ひとこと「使いすぎを、月の途中で先回り。」 |
| 月の切り替え | 「‹」「2026年10月」「›」。この1か所だけで、画面全体の月が変わる。今月以外のときは「今月へ」を出す。月の名前は読み上げで知らせる |

### 今月のペース
見出しは 今月「今月のペース」／過去「この月のふりかえり」／先「この月の予定」。

| 状態 | 表示 |
|---|---|
| 記録なし | ノートの絵と「まだ記録がありません。金額と費目をえらんで書きこむと、月末の見込みがここに出ます。」 |
| 今月・記録あり | 「このままだと月末」＋大きな金額（こえるときは朱）。判定の札（下表）。図。予算・使った・残りの3列。「残り○日（今日をふくむ）。1日 ¥○ までなら予算に収まります。」。1〜4日目は「見込みが大きくぶれます」 |
| 過去の月 | 「この月の合計」＋金額。「予算より ¥○ 少なく収まりました／予算を ¥○ こえました」。図（実績だけ）。3列 |
| 先の月 | 「まだ始まっていない月です」「予定として書いた額」 |
| 予算なし | 上に加えて「予算を決めると、使いすぎを先に知らせます。」と「予算を決める」（押すと予算の欄へ） |

| 判定 | 条件 | 札 |
|---|---|---|
| 収まる | 見込み ≦ 予算の9割 | 緑「予算内のペースです（余裕 ¥○）。」 |
| ぎりぎり | 予算の9割 ＜ 見込み ≦ 予算 | 黄「予算ぎりぎりのペースです（余裕 ¥○）。」 |
| こえそう | 見込み ＞ 予算 | 朱「このままだと予算を ¥○ こえます。」 |
| こえた | 使った ＞ 予算 | 朱「予算を ¥○ こえています。」 |

図（SVG、横 640 × 縦 280 の比で幅いっぱい）: 罫線、1日からの累計（紺の実線と薄い面）、今日の点、見込み（点線、こえるときは朱）、月末の見込みの白丸、予算（朱の線）、予算どおりのペース（点の斜線）、こえるときは予算より上を薄い朱。下に「1日／今日／末日」と凡例。図には文の説明（aria-label）を付ける。

### 書きこむ
| 部品 | 仕様 |
|---|---|
| ① 金額 | 下線だけの大きな欄（明朝 2.3rem）。数字キーボード。欄を離れると3桁区切り。Enter で保存 |
| ② 費目 | 絵つきの9つ（3×3）。選ぶと紺の枠と点。矢印キーで選べる |
| 日付・メモ | 開閉式。閉じていても右に「今日」などを表示。日付（2000〜2100年）とメモ（40文字） |
| ③ 書きこむ | 幅いっぱいの紺のボタン。直すときは「直す」と「やめる」 |
| 注意 | 「金額を入れてください。」「数字だけで入れてください（例: 1200）。」「1円以上で入れてください。」「99,999,999円までです。」「費目をえらんでください。」「日付を入れてください（2000〜2100年）。」。誤りの欄にカーソルを移す |
| 保存後 | 「外食 1,200円 を書きました」＋「元に戻す」。ほかの月の日付なら「（2026年9月のページに）」を添える |

### 費目ごと
絵・費目名と件数・横棒（いちばん多い費目を100%）・金額と割合。多い順。記録がなければ案内文。

### 記録
左に朱の余白線と罫線のノート。日ごとの見出し「10月23日（金）」と日の合計。1行ずつ 絵・費目・メモ・金額・直す・消す（44px、読み上げは「10月23日（金）の外食 1,200円を直す」）。320px 幅では絵と余白線を省く。

### 予算とデータ
| 部品 | 仕様 |
|---|---|
| 1か月の予算 | 「2026年10月から」の欄と「予算を決める」（Enter でも可）。下に「2026年9月に決めた予算を引き継いでいます。」など |
| ほかの端末へ移す | 「バックアップを書き出す（JSON）」「表計算用に書き出す（CSV）」「ファイルを読み込む」（.json / .csv、5MBまで） |
| 記録を消す | 「全部消す」→ その場に「本当に消しますか？ 先にバックアップを書き出しておくと安心です。」と「消す」「やめる」 |

### 下部
「記録は、このスマホ（ブラウザ）の中にだけ残ります。キャッシュと同じで、外には送りません。」とほかのアプリへのリンク。保存できない環境では朱で「この画面では保存できないため、閉じると記録が消えます。」。素材の権利表記は画面に出さず、`art/LICENSES.md` と各ライセンス本文を同梱する。

## 4. 保存する内容
localStorage のキー `kakeibo.notebook.v2` に `{ expenses: [{ id, date, amount, cat, memo, at }], budgets: { "YYYY-MM": 金額 } }`。読み込み時に形と範囲（実在する日付、1〜99,999,999円、知っている費目、メモ40文字、id の文字）を検査する。全体が壊れていれば初期状態にし、元の文字列は `kakeibo.notebook.v2.broken` に取っておく。前の版のキー（`kakeibo.expenses` / `kakeibo.budgets`）は引き継いで消し、`kakeibo.llm`（API キー）は消す。
