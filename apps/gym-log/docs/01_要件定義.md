## 1. 目的
ジムでトレーニングする人が、**スマホを片手に、セットの合間の数秒で、重さと回数を記録できる**ようにする。前回の記録が次の入力に入り、伸びたらすぐ分かるので、**続けたくなる**。

### 1.1 想定する場面
- 24時間営業の小さなマシンジム（無人・マシン中心）に、仕事帰りに30分だけ寄る。チェストプレス → ラットプルダウン → バイク。前回より 2.5kg 重くできたか知りたい。
- 汗をかいた指で、手袋をしたまま、音楽を聞きながら操作する。
- 家で腕立て伏せ・スクワット・プランクだけやる日もある。

### 1.2 やらないこと
- iPhone の「ヘルスケア」・Google Fit（ヘルスコネクト）への書き込み・読み込み（ウェブのアプリからはできない。ネイティブアプリが必要なため対象外）
- 会員登録・サーバーへの保存・ほかの人との共有
- 外部の AI によるメニュー作成（API キーが要るため。代わりに端末内の「今日のおすすめ」で補う）
- 体重・食事の記録、動画での動きの説明
- 特定のジムの名前やロゴの使用（マシンは一般名で収録）

## 2. 利用者
| 利用者 | 特徴 | 求めること |
|---|---|---|
| 初心者（主） | ITに詳しくない。マシンの名前もうろ覚え | 絵でマシンが分かる。入力は「＋」「−」と大きなボタンだけ |
| 続けている人 | 週2〜3回。前回の重さを覚えていない | 前回の数がすぐ出る。伸びたら分かる |

## 3. 機能要件

### F1 種目
- F1-1 最初から21種目を選べる。マシン12（チェストプレス・ラットプルダウン・ショルダープレス・アームカール・ディップス（マシン）・アブドミナル・バックエクステンション・ロータリートルソー・レッグプレス・レッグエクステンション・アダクション・アブダクション）、有酸素2（バイク・ウォーキングマシン）、自重7（腕立て伏せ・懸垂・ディップス・スクワット・ランジ・クランチ・プランク）。
- F1-2 **種目ごとに絵**（器具と人の形、鍛える場所を差し色で）を出す。
- F1-3 部位（胸・背中・肩・腕・お腹・脚・有酸素）でしぼれる。
- F1-4 自分で種目を作れる（名前24文字まで・部位・記録のしかた・重さの刻み）。絵は部位の絵になる。
- F1-5 使わない種目は隠せる。隠した種目は戻せる。

### F2 記録
- F2-1 「トレーニングを始める」で記録を始め、「終わる」で閉じる。記録中は経過時間・セット数・前のセットからの休けい時間を出す。
- F2-2 記録のしかたは4つ: 重さ×回数 / 回数だけ / 秒 / 分。
- F2-3 入力は「＋」「−」（重さは種目ごとの刻み 0.5/1/2.5/5kg、秒は5秒）と、数字の直接入力（全角も可）。重さ 0〜500kg、回数 0〜999、秒 0〜3600、分 0〜300。
- F2-4 **次のセットの初期値**は、今日の直前のセット → 前回の同じ番目のセット → 前回の最後のセット → 種目の初期値（20kg×10回 など）の順。
- F2-5 セット・種目を消せる。消したら「元に戻す」で戻せる。
- F2-6 記録中にページを閉じても、開き直すと続きから。

### F3 続けたくなる工夫
- F3-1 種目ごとに「前回 日付・全セット」を出す。
- F3-2 記録する前に、入力中の数が「自己ベスト」「前回より上」「前回と同じ」かを出す。
- F3-3 記録したセットに印（自己ベスト／前回より上／前回と同じ）を付け、お知らせを出す。
- F3-4 終わったら「おつかれさまでした」のまとめ（時間・セット数・総重量・自己ベストの数・前回より伸びた種目）。減った数は出さない。
- F3-5 今週やった日（月〜日の印）、続けている週の数、今週の総重量。
- F3-6 今日のおすすめ: 上半身と下半身を交互に。今日やった・2日続けたなら「休む日」。おすすめの種目で、または「前回と同じ種目で」1回押すだけで始められる。
- F3-7 種目ごとの自己ベストと、伸びのグラフ（直近12回）。

### F4 履歴・バックアップ
- F4-1 履歴を新しい順に。日付・種目の絵・時間・セット数・総重量。開くと中身、消せる（元に戻す付き）。
- F4-2 バックアップの書き出し・読み込み（JSON。前の版のバックアップも読める）。表計算用の CSV。
- F4-3 見本の記録（4週間分）を入れて試せる。記録が空のときだけ。
- F4-4 すべて消す（2段階で確認）。

### F5 その他
- F5-1 画面の色を 自動／明るい／暗い から選べる。
- F5-2 記録中は画面を消さない（対応ブラウザのみ。設定で切れる）。
- F5-3 前の版（v1）の保存内容があれば、初回に引き継ぐ。
- F5-4 一度開いた端末では、電波がなくても開いて記録できる。ホーム画面に追加できる。

## 4. 非機能要件
| 区分 | 要件 |
|---|---|
| 対応環境 | iOS Safari 16以上、Android Chrome 最新、PC の Chrome / Safari / Edge 最新 |
| 画面幅 | 320px〜1440px で崩れない。主は 390px。PC では2列 |
| 使いやすさ | 押せるものは 44×44px 以上（主な「＋」「−」は 60×64px、記録ボタンは高さ 60px）。入力欄の文字は 16px 以上（数字は 2.3rem） |
| アクセシビリティ | WCAG 2.2 AA。コントラスト 4.5:1 以上。キーボードだけで全操作できる |
| 個人情報 | 記録は端末内（localStorage `gym-log.v2`）だけ。外部への通信 0 件。アクセス解析なし |
| 安全 | 利用者の入力（種目名）は必ず無害化して出す。CSV は表計算で式として動かないようにする |
| 見た目 | モノトーン（黒・白・グレー）＋差し色ライム #c8f04a。数字は Oswald、日本語は Zen Kaku Gothic New |

## 5. 受け入れ基準
| No | 確認すること | 合格の条件 |
|---|---|---|
| AC-01 | 初めての人が使える | 説明なしで、チェストプレスを2セット記録して終えるまで **90秒以内**（3人で確認） |
| AC-02 | 前回が初期値になる | 2回目に同じ種目を選ぶと、前回の重さ・回数が入っている（自動テスト） |
| AC-03 | 伸びが分かる | 前回より重いと「自己ベスト」、多いと「前回より上」が出る（自動テスト） |
| AC-04 | 計算が正しい | 総重量・自己ベスト・続けた週・増減の性質がランダム 1万件以上で成り立つ |
| AC-05 | 入力の揺れ | 全角・単位付き・空・上限超えで落ちない |
| AC-06 | 保存の安全 | 壊れた保存内容・前の版の保存内容で落ちない |
| AC-07 | 端末 | iPhone 実機（Safari）と Android 実機（Chrome）で全操作 |
| AC-08 | オフライン | 機内モードで開いて記録できる |
| AC-09 | アクセシビリティ | axe 違反 0 件 |
| AC-10 | 画面 | 320 / 390 / 768 / 1280px、ライト / ダークで崩れ・重なり・はみ出し 0 件 |
| AC-11 | 個人情報 | 外部への通信 0 件 |

## 8. 合意した事項（2026-10-23、指示書より）
- 「ショボい・ほかのアプリと同じ色・文字だけ」の指摘を受け、見た目を一新し、種目ごとに絵を入れる。
- 小さなマシンジムで使う人を想定し、マシン中心の種目を最初から選べるようにする。商標名（ジムの名前）は使わない。
- ヘルスケア・Google Fit 連携は対象外（1.2）。
- 前回の記録を次のセットの初期値にし、伸びたら分かるようにする。

## 9. 発注者に決めてほしいこと
- マシンの重さの刻みの初期値（いまは 2.5kg、レッグプレスだけ 5kg）
- 見本の種目の並び（いまはマシン → 有酸素 → 自重）
