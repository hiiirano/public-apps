# 冷蔵庫つめつめパズル

子どもが冷蔵庫へ入れたリモコンや靴下を回収し、傷んだ食材を見つけ、食材を正しい棚へ戻す短時間ロジックパズルです。

## ミッション

1. **リモコンはどこ!?** — 食べ物ではない謎アイテムを回収
2. **なんか臭うぞ…** — 傷んだ食材だけを見つけて廃棄
3. **ぜんぶぐちゃぐちゃ！** — 回収・廃棄・冷凍室/冷蔵室/野菜室への並べ替え

ログイン・通信・サーバーは不要です。ゲーム判定は `src/game.ts` の純関数へ分離しています。

## 拡張設計

無限生成と家庭内コメディを両立する方針、60個以上のミッション案、開発ロードマップ、Antigravity向け第1実装ブリーフは [`EXPANSION_DESIGN.md`](EXPANSION_DESIGN.md) にまとめています。

## 開発

```bash
npm install
npm run dev
npm test
npm run build
```
