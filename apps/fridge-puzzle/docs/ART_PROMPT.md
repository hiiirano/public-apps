## 2. ChatGPT に渡すプロンプト
シートを分けて頼む（1 枚に入れすぎると崩れるため）。できたら 1 つずつ切り出し、白を透明にして WebP（品質 82）にする。

### シート1: 食べ物（6列×7段）
```
ゲーム用のアイコンシートを1枚描いてください。
画風: ぷっくりした3Dクレイ風、やわらかい光、はっきりした輪郭、彩度高め、ポップなゲームセンターの雰囲気。影は落とさない。文字は入れない。
背景: 無地の白。各アイコンの間は十分にあける（切り抜くため）。
並び: 6列×7段の格子。各マスに1つずつ、正面からやや斜め上の視点で、マスいっぱいに大きく。
同じ画面に並べても見分けやすいよう、形と色をはっきり変える。
描く物（左上から順に）: お肉、とりもも、ベーコン、刺身、さかな、えび、ブロッコリー、にんじん、トマト、葉っぱ野菜、なす、たまねぎ、きゅうり、きのこ、たまご、牛乳、チーズ、バター、ビール、プロテイン、日本酒、お茶、作り置き、残り物、カレー、納豆、ぎょうざ、おでん、プリン、ケーキ、アイス、りんご、レモン、いちご、なぞのびん、氷、ほにゅうびん
「なぞのびん」は中身の分からない透明なびん。「作り置き」は四角い保存容器に入った惣菜。「残り物」は中華の持ち帰り箱。「納豆」は納豆のパック。「プロテイン」はシェイカーボトル。
```

### シート2: 人物（5列×5段）
```
ゲーム用のキャラクターシートを1枚描いてください。シート1と同じ画風（ぷっくりした3Dクレイ風、ポップ、彩度高め）。
背景: 無地の白。各キャラの間は十分にあける。文字は入れない。
並び: 5列×5段。各キャラは正面向きの全身（2.5頭身くらい）、少し間の抜けた真顔で、右手を体の右下で軽く開いている（あとで持ち物を重ねるため、手には何も持たない）。
シルエットだけで誰か分かるよう、服・髪型・小物で描き分ける。体型や年齢そのものを笑いものにしない、ファミリー向けの脱力コメディのトーン。
描く人物（左上から順に）: マッチョなお兄さん、おばあちゃん、こども、会社員のお姉さん、コックさん、宇宙飛行士、忍者、名探偵、ゾンビ、ねこ、宇宙人、サンタさん、魔法使い、農家のおじさん、ペンギン、吸血鬼、赤ちゃん、ヒーロー、シロクマ、エンジニア、おじいちゃん、お姫さま、上を指す人差し指（手の甲側）、クラッカー、赤いはてなマーク
```

### アプリのアイコン
```
アプリのアイコンを1枚描いてください。シート1と同じ画風。
紺色（#1b1446）の正方形の背景に、ミント色（#7ef0c6）の2ドア冷蔵庫を正面から大きく。冷蔵庫に、寒くて青ざめた顔のキャラクターが張りついている。文字なし。四隅が丸く切られても冷蔵庫が欠けないよう、中央の8割に収める。
```

## 3. 差し替えたら
- `public/art/LICENSES.md` の出典を「ChatGPT（OpenAI）で本アプリ用に作成」に書きかえ、Fluent Emoji の行を消す。
- `npm run test:e2e` で画面検査をやり直し、スクリーンショットを目で確認する。
