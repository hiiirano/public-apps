# ヒエヒエ冷蔵庫

甘い物だらけの冷蔵庫を見て、説明なしの4人から持ち主を選ぶ短時間の理不尽ミニゲームです。正解に論理的な根拠はありません。

## 1ラウンド

1. 専用イラストの冷蔵庫を見る
2. 4人から持ち主を選ぶ
3. 約1秒の間の後、根拠のない正解が発表される
4. 同じ問題と自分の回答を含むURLを友達へ送る
5. 友達の回答後、正解・自分・送信者の選択を比較する

ログイン・通信・サーバーは不要です。問題ID、seed、キャラ順、送信者の選択位置はURL fragmentで保持し、破損したURLは新規ラウンドへ戻ります。ゲーム判定と共有URL処理は `src/game.ts` の純関数へ分離しています。

## 拡張設計

無限生成と家庭内コメディを両立する方針、60個以上のミッション案、開発ロードマップ、Antigravity向け第1実装ブリーフは [`EXPANSION_DESIGN.md`](EXPANSION_DESIGN.md) にまとめています。

その後の企画検討で、冷蔵庫単体の長期パズルではなく、理不尽な短編ゲーム集の一作 **「ヒエヒエ冷蔵庫」** として再構成し、最初の縦切りを実装しました。

- [`CORE_REDESIGN.md`](CORE_REDESIGN.md) — ヒエヒエ冷蔵庫、キャラクター4択、共有比較の検討過程
