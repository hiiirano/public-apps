# 在庫管理 — リリースノート

## v2.0.0（2026-10-23）
冷蔵庫・冷凍庫・棚を絵で見せる在庫管理として作り直した。

### できること
- よく買う物 32 種を絵のボタンで入れる（いつもの置き場所と期限のめやすで入る。よく押す物が先に並ぶ）
- ほかの物も名前・絵・置き場所・数・期限を入れて追加。名前から絵を当てる
- 冷蔵庫・冷凍庫・棚の絵の中に食材の絵が並び、期限の近さを色と言葉（「今日まで」「明日まで」「あと2日」「1日すぎ」）で表示
- 「そろそろ使う物」から、その場で「使った」「捨てた」
- この30日の「使い切った」「捨てた」の数と割合、「買いすぎかも」の知らせ
- 書き出し（JSON ファイル）と読み込み。見本データ。すべて消す。どの操作も「元に戻す」
- 一度開けばオフラインでも使える。ホーム画面に追加できる

### 前の版（v0.1）から変わったこと
- AI 連携（レシートの取り込み）と API キーの入力をなくした。端末に残っていた AI 設定は自動で消す
- 数を「1つ・2つ」に絞り、単位・カテゴリ・最低在庫・メモをなくした
- 期限の計算を、時差・夏時間・月末・うるう年でずれない方法に変えた
- 外部のフォント配信をやめ、通信をしないようにした（CSP で外部への接続を禁止）
- 保存形式を v2（`pantry-tracker.v2`）にした。v0.1 の在庫は名前・数・置き場所・期限を引き継ぐ

### 既知の問題・制限
- 食材の絵は仮（Microsoft Fluent Emoji）。差し替え用の指示書は docs/ART_PROMPT.md
- 名前の漢字など、同梱フォントにない文字は端末のフォントで表示される
- 家族の端末どうしで同期はできない（書き出し・読み込みで移す）
- アプリを更新しても、すでに開いたことのある端末では、次に開いたときに新しい版になる（オフライン対応のため）
- 実機（iPhone・Android）での確認と、利用者テストは未実施（テスト計画書 §4・§5）
