# 週間献立プランナー — リリースノート

## v3.0.0（2026-10-23）
1週間の夕食を、料理の絵を大きく並べて眺められるアプリとして作り直した。

### できること
- 大人・子どもの人数、ジャンル（おまかせ／和食多め／洋食多め／中華多め）、食物アレルギー9品目、苦手なもの、冷蔵庫の残りから、7日分の夕食を作る
- 毎日「主菜＋副菜＋汁物」。副菜・汁物は付けない設定も可。20分以内の料理だけにもできる
- 苦手なもの・残り物は絵つきのボタンで選べる。自由入力も可。ネギ／ねぎ／葱、人参／ニンジンなどの言い方の違いをそろえて判定する
- 残り物を何曜日のどの料理で使うかを表示。使えないもの（例: リンゴ）はそう表示
- 日ごとに夕食を開閉、「この日を変える」でその日だけ変更、「別の組み合わせ」で週全体を変更
- 人数分にまとめた買い物リスト（チェック・コピー）、献立のコピー
- 条件・チェックを端末に保存して次回も同じ献立。一度開けばオフラインでも使える。ホーム画面に追加できる

### 前の版（v2）から変わったこと
- **苦手なもの**: 部分一致をやめ、分類（牛肉・豚肉・ねぎ類・きのこ類など）と言い換え辞書で判定。「牛肉」で牛こま切れ肉・合いびき肉の料理、「ネギ」で長ねぎの料理が外れる。玉ねぎは別扱い
- **冷蔵庫の残り**: 同じ辞書で照合し、使う料理を優先。どこで使ったかを表示
- **ジャンル**: 「選んだジャンルだけ」から「多め（7日のうち4日）」に変更。和を選んでも洋・中が混ざる
- **品数**: 1日1品から主菜＋副菜＋汁物に。汁物を8品追加し、料理は149品に
- **見た目**: 緑系に一新。料理の絵を Fluent Emoji 3D にして大きく表示。PC は左に条件・右に献立の2列。ダークモード対応
- 「作る」ボタンをなくし、条件を変えるとすぐ作り直す
- 外部への通信をなくし（CSP で禁止）、フォントを同梱。オフライン対応（Service Worker）
- 保存形式を v3 にした。v2 の条件（人数・アレルギー・苦手・残り物）は引き継ぐ

### 既知の問題・制限
- 朝食・昼食は出さない（料理データが夕食向けだけのため。要件定義 §1.2）
- 作り方・栄養は出さない
- アレルギーの判定は9品目だけ。料理データの材料と加工品の一般的な原材料で判定しており、商品ごとの原材料の違いや調理時の混入は判定できない
- 料理の絵は料理ごとではなく、種類ごとの共通の絵（48点）
- 入力した言葉の漢字など、同梱フォントにない文字は端末のフォントで表示される
- 条件を変えると「この日を変える」で変えた日は元の組み合わせに戻る
- 実機（iPhone・Android）での確認と、利用者テストは未実施（テスト計画書 §4・§5）
