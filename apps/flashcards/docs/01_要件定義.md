## 1. 目的
**紙の単語カード（リングでとじた単語帳）を1枚ずつめくる気持ちよさ**のまま、忘れかけたころに同じカードをもう一度出して、無理なく覚えられるようにする。

前の版（v1）は「Anki みたいで正直微妙」と言われた。Anki の機能を追うのではなく、次の3つに絞る。
- めくる: 大きなカードを1枚ずつ。めくるアニメーション。答えは4つのボタンだけ
- すぐ始められる: 見本の単語帳、貼り付けでまとめて作成。API キーや登録は要らない
- 続けたくなる: 今日の分が終わると「大変よくできました」のはんこ、つづけた日数

### 1.1 想定する場面
- 中学生が、通学の電車で英単語20語をめくる。わからない単語は少しあとにもう一度出る。
- 大人が、エクセルにまとめた資格試験の用語（表・裏の2列）を貼り付けて、単語帳を作る。
- 機種変更の前に、データを書き出して新しいスマホで読み込む。

### 1.2 やらないこと
- AI でカードを作る機能・外部への通信（v1 にあった AI 生成と API キー入力は削除）
- 画像・音声のカード、穴うめ、単語帳の入れ子
- 複数の端末での自動同期（書き出し・読み込みで手で移す）
- 細かい学習の統計グラフ

## 2. 利用者
| 利用者 | 特徴 | 求めること |
|---|---|---|
| 学生（主） | スマホで、すきま時間に。片手操作 | 開いてすぐめくれる。今日あと何枚か分かる |
| 大人の学び直し（主） | IT に詳しくない人もいる | 作り方で迷わない。表を貼るだけで作れる |
| 先生・親（従） | 単語帳を作って子どもに渡す | 書き出したファイルを渡せる |

## 3. 機能要件

### F1 単語帳
- F1-1 単語帳を名前（30文字まで）で作る。空なら「新しい単語帳」。
- F1-2 一覧に、単語帳ごとに 全枚数・覚えた枚数（3回つづけて思い出せた）・進み具合の帯・「めくる ○枚」を出す。
- F1-3 名前を変えられる。消せる（「元に戻す」で取り消せる）。
- F1-4 見本の単語帳を入れられる: 中学英単語 20 / 都道府県の県庁所在地（47）/ 元素記号 1〜20番。入れた見本は「開く」に変わる。

### F2 カードを入れる
- F2-1 **まとめて入れる**: 1行に「表<タブ>裏」または「表,裏」（全角の「，」も可）。区切りのない行は2行で1枚（表・裏の順）。
- F2-2 貼り付けると、すぐに「○枚 作れます」と最初の3枚、入れられない行（行番号と理由）を出す。
- F2-3 同じ単語帳にまったく同じ表・裏があるものはとばす。
- F2-4 **1枚ずつ入れる**: 表・裏を入れて「1枚入れる」。空なら注意を出す。
- F2-5 カードを直す・消す（消すは「元に戻す」で取り消せる）。
- F2-6 「文字でコピー」で、単語帳を「表<タブ>裏」の文字にしてコピーする（F2-1 にそのまま貼れる）。
- F2-7 表・裏はそれぞれ 300 文字まで。カードは全部で 20,000 枚まで。

### F3 めくる
- F3-1 今日めくるカード = 復習の日が来たカード（日が古い順）＋ 新しいカード（入れた順、1冊につき1日 20 枚まで。5/10/20/30/50 から選べる）。
- F3-2 カードの表を大きく出す。「めくって答えを見る」かカードを押すと、裏返るアニメーションで答えを出す。
- F3-3 答えは4つ。ボタンに次に出る日を書く（例「わかった 次はあさって」）。
  | ボタン | 次に出す日（初めて / 2回目 / 3回目から） |
  |---|---|
  | わからない | この回のうちに3枚あとでもう一度。次の日も出す |
  | むずかしい | 1日 / 3日 / 前の間隔×1.2（最低+1日） |
  | わかった | 2日 / 6日 / 前の間隔×覚えやすさ（最低+1日） |
  | かんたん | 4日 / 10日 / 前の間隔×覚えやすさ×1.3（最低+2日） |
  覚えやすさは 2.5 から始まり、答えによって 1.3〜3.0 の間で変わる（SM-2 と同じ増減）。間隔は最長 10 年。
- F3-4 答えるとカードがめくれて飛び、次のカードが出る。押しまちがえたら「ひとつ戻す」。
- F3-5 キーボード: スペース・Enter でめくる、1〜4 で答える。
- F3-6 端末の「視差効果を減らす（動きを減らす）」設定では、アニメーションをすべて止める。

### F4 ごほうび
- F4-1 今日の分が終わると、「大変よくできました」のはんこが押される画面を出し、答えの内訳（わからない・むずかしい・わかった・かんたん）を出す。
- F4-2 めくった日を記録し、何日つづけているかを出す（今日まだなら昨日まで）。
- F4-3 一覧の「今日の分」に、今日めくる枚数の合計か「今日の分は、ぜんぶ終わりました」を出す。

### F5 データ
- F5-1 端末に保存し、次に開いたとき続きから。保存できない環境でもめくれる（その旨を出す）。
- F5-2 **書き出す**: すべての単語帳・カード・めくった日を JSON ファイルにする（`anki-cards-YYYYMMDD.json`）。
- F5-3 **読み込む**: ファイルを選ぶと中身（○冊・○枚）を見せ、「今のデータに足す」か「今のデータと入れかえる」を選ぶ。どちらも「元に戻す」で取り消せる。同じカードは足さない。
- F5-4 読めないファイル・壊れた保存内容は知らせる。壊れた保存内容は消さずに控えを残す。
- F5-5 前の版（v1）の保存内容があれば引き継ぐ。

### F6 電波がなくても使える
- F6-1 一度開いた端末では、オフラインでも開いてめくれる。ホーム画面に追加できる。

## 4. 非機能要件
| 区分 | 要件 |
|---|---|
| 対応環境 | iOS Safari 16以上、Android Chrome 最新、PC の Chrome / Safari / Edge 最新 |
| 画面幅 | 320px〜1440px で崩れない。PC 幅では一覧2列、単語帳の画面は「入れる」と「カード」を2列 |
| 使いやすさ | 押せるものは 44×44px 以上。入力欄・本文の文字は 16px 以上 |
| アクセシビリティ | WCAG 2.2 AA。コントラスト 4.5:1 以上。キーボードだけで全操作。めくる前の答えは読み上げない |
| 個人情報 | 外部への通信 0 件。アクセス解析なし |
| 安全 | 入力した文字は無害化して表示。公開版は CSP で外部への接続・外部スクリプトを禁止 |
| 計算の正しさ | 間隔の計算は純関数（srs.ts）。日付は端末の暦日で数え、夏時間・うるう年でずれない |
| 見た目 | 紙の単語カード。藍（#22407a）と生成り（#f4eedf）。ダークモード対応 |

## 5. 受け入れ基準
| No | 確認すること | 合格の条件 |
|---|---|---|
| AC-01 | 初めての人が使える | 説明なしで、見本を入れて5枚めくるまで 60 秒以内（3人） |
| AC-02 | 自分のカードを作れる | エクセルの2列をコピーして貼り付け、単語帳ができる（3人） |
| AC-03 | 間隔の計算 | 境界の単体テストと、ランダム 2 万件の性質テストがすべて合格 |
| AC-04 | 貼り付け | タブ・カンマ・全角カンマ・2行で1枚・空行・引用符・Windows の改行を正しく扱う |
| AC-05 | データ | 書き出し → 別の端末で読み込み、同じ単語帳・進み具合・つづけた日数になる |
| AC-06 | 動き | 動きを減らす設定でアニメーションが止まる |
| AC-07 | オフライン | 機内モードで開いてめくれる |
| AC-08 | アクセシビリティ | axe で違反 0 件 |
| AC-09 | 画面 | 320 / 390 / 768 / 1280px、ライト / ダークで崩れ・重なり・はみ出し 0 件 |
| AC-10 | 個人情報 | 外部への通信 0 件 |
