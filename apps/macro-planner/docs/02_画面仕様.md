1画面で完結する。スマホ（〜959px）は縦1列。PC（960px〜）は上段の左に「1 あなたのこと」、右に「2 1日の目標」、下段に「3 食べたものを記録」を横いっぱいに置く。

## 1. 画面の並び

| 順 | 区画 | スマホ | PC |
|---|---|---|---|
| 0 | 上部（アプリ名・見出し・説明・サラダの絵） | 1列 | 同じ（絵を大きく） |
| 1 | ① あなたのこと | ↓ | 左 |
| 2 | ② 1日の目標（結果） | ↓ | 右 |
| 3 | ③ 食べたものを記録 | ↓ | 下段（中を「よく食べるもの」と「この日に食べたもの」の2列に） |
| 4 | 下部（書き出す・読み込む・すべて消す・注意・保存の説明） | ↓ | 中央 |
| — | お知らせ（記録・削除・元に戻す） | 画面下に一時表示 | 同じ |

## 2. 区画ごとの部品

### ① あなたのこと
| 部品 | 仕様 |
|---|---|
| 性別 | 「女性」「男性」の2択（丸いボタン、高さ 52px）。初期値なし |
| 年齢・身長・体重 | 文字 1.25rem 太字・高さ 52px。数字キーボード（inputmode）。単位を右に。380px 未満は縦1列、以上は横3列 |
| 欄の注意 | 範囲外「18〜100 の数で入れてください。」、文字「数字で入れてください。」。枠を赤にし、結果は直前の値のまま |
| ふだんの動き | 5つの札（絵・名前・説明）。選ぶと緑の枠と淡い緑の地 |
| 目的 | 3つの札（絵・名前・説明）。600px 以上は横3列 |
| PFC の割合を変える | 開閉式。たんぱく質（g/kg）・脂質（%）の欄と説明、「はじめの値に戻す」 |

### ② 1日の目標
| 状態 | 表示 |
|---|---|
| 未入力 | お皿の絵、「性別・年齢…を入れると、ここに1日の目標カロリーと PFC が出ます。」（足りない項目を太字で）、「見本の値で試す」 |
| 計算できた | 目標カロリー（数字 3.4〜4.8rem、緑）＋ kcal、目的の言葉（「いまの体重をたもつ量」）。PFC のリング（直径 168px、P 朱・F 山吹・C 青）と、3行の一覧（色の点・名前・グラム 1.6rem・割合・国の目安）。国の目安から外れたときの知らせ。「1日の食事の目安」5枚（1食あたり／ごはん／鶏むね肉（卵）／食パン／バター）。基礎代謝・1日の消費・BMI の3つの箱。BMI 22 の体重。「計算のしかた」（開閉式） |
| 基礎代謝まで引き上げ | 黄色の帯で「減らしすぎないよう、基礎代謝（○ kcal）まで引き上げています。」 |
| 炭水化物が足りない | 黄色の帯で「たんぱく質と脂質だけで目標カロリーを超えています。…少なくしてください。」 |

- 入力のたびにすぐ計算し直す。画面読み上げには、入力が 1.2 秒止まってから「目標は1日 ○キロカロリー。たんぱく質 ○g…」と伝える。

### ③ 食べたものを記録
| 部品 | 仕様 |
|---|---|
| 日付 | 日付の欄と「今日」ボタン |
| 合計 | 「あと ○ kcal 食べられます」（数字 2.1rem）／超えたら赤で「目標より ○ kcal 多く食べています」。カロリーの棒（緑）と PFC の棒（各色）。目標がないときは合計と案内だけ |
| よく食べるもの | 14品のタイル（絵・名前・量・kcal）。2列 → 520px〜3列 → 1100px〜4列。押すと1つ記録し「○○を記録しました［元に戻す］」 |
| そのほかの食べ物 | 開閉式。名前・カロリー・たんぱく質・脂質・炭水化物と「記録する」。注意は欄の下 |
| この日に食べたもの | 新しい順。名前・kcal・PFC・ごみ箱（48px、読み上げ「○○を消す」）。消すと見出しにフォーカスを移し「元に戻す」付きのお知らせ（8秒）。空なら「まだありません。…」 |

### 下部
| 部品 | 仕様 |
|---|---|
| 記録を書き出す | `pfc-kiroku-YYYY-MM-DD.json` を保存 |
| 書き出した記録を読み込む | このアプリの形のファイルだけ読む。読めなければ「読み込めませんでした。…」 |
| すべて消す | 体のことと記録を消す。「元に戻す」付き |
| 注意 | 「計算は一般的な式による目安です。病気の治療中・妊娠中・成長期の人は、医師や管理栄養士の指示を優先してください。」 |
| 保存の説明 | 「入力した内容は、このスマホ（ブラウザ）の中にだけ残ります。キャッシュと同じで、外には送りません。」と「ほかのアプリ」。素材の権利表記は画面に出さず、`art/LICENSES.md` ほかとして同梱する |
| 保存できない環境 | 「この画面では保存できないため、閉じると入力が消えます（計算はできます）。」 |

## 4. 保存する内容
端末の localStorage（キー `macro-planner.v2`）に次を保存する。読み込み時に形と範囲を検査し、体のことが壊れていれば初期状態、記録は正しいものだけ残す。

| 内容 | 形 |
|---|---|
| draft | 性別（null 可）・年齢・身長・体重（null 可）・動き・目的・たんぱく質 g/kg・脂質 % |
| log | 記録の配列（id・名前・kcal・P・F・C・日付 YYYY-MM-DD・記録した時刻）。最大 3,000件 |

前の版のキー（`macro.profile` / `macro.log` / `macro.llm`）は、初回に引き継いでから消す。
