## 1. 目的
暑い日に新宿駅のまわりを歩く人が、**「いちばん近い道」と「地下・屋根の下を通る道」をくらべ、日なたを歩く時間がどれだけ減るかを一目で分かる**ようにする。

### 1.1 想定する場面
- 8月の昼。新宿駅西口から新宿区役所へ行く。近い道は地上を8分ほど歩くが、地下街を通れば日なたは1分ほどで済む。1分遠回りしてもいいか、その場で決めたい。
- 東口から新宿三丁目駅へ。地上を歩かずに地下だけで行けるかを知りたい。

### 1.2 やらないこと
- 建物の影・街路樹の影の計算（時刻・季節ごとの日陰）
- 天気・気温・UV 指数との連動
- 好きな場所の入力、GPS の現在地、道案内（ナビ）
- 外部の地図サービス・地図タイル・道さがしサービスの利用（通信 0 件を守る）
- 営業時間・工事・閉鎖のリアルタイム反映、バリアフリーの保証
- 新宿以外の街（梅田などは別の版で検討）

## 2. 利用者
| 利用者 | 特徴 | 求めること |
|---|---|---|
| 新宿を歩く人（主） | IT に詳しくない。暑さに弱い・子ども連れ・高齢など。駅や店先でスマホを片手に見る | 2つの道の違い（日なたの時間・歩く時間）が数字と絵ですぐ分かる |
| 初めて新宿を歩く人（従） | 地下街の名前が分からない | 「どこで地下に入り、どこで地上に出るか」が順に分かる |

## 3. データの範囲と限界（正直に書くこと）
| 項目 | 今の扱い | 限界 |
|---|---|---|
| 範囲 | 新宿駅まわりの選べる5か所（東京都庁・新宿駅西口・新宿駅東口・新宿区役所・新宿三丁目駅）と、途中の4地点。道は12区間 | 5か所の間しか調べられない。地下街の中の細かい道は1本にまとめている |
| 日陰とした道 | 「地下通路」（6区間）と「屋根の下」（駅の東西自由通路の1区間） | 地下でも暑い所・屋根の切れ目がある所は区別していない |
| 日なたとした道 | 屋根のない地上の道（5区間）は**すべて日なた**として数える | 実際はビル・街路樹・アーケードの影になる所もある。日なたを多めに見積もる側に倒している |
| 根拠 | 新宿区「新宿ターミナルマップ」（2025年11月版）・東京メトロ構内図・新宿区の整備案内・区役所アクセス案内を、2026年8月23日に人が見て手で入力。区間ごとの根拠は画面の「道ごとの根拠を見る」と `src/cities/shinjuku.ts` の `basis` にある | 現地を歩いて確かめてはいない |
| 距離 | 公式の地図の縮尺から読み取った概算（10m 単位） | 実測ではない。±20% ほどずれうる |
| 季節・時刻 | **考えない**。朝でも夜でも、夏でも冬でも同じ答え | 夜間・早朝は地下街や通路が閉まり、出てくる道が通れないことがある（画面で注意を出す） |
| 歩く時間 | 分速60m（階段・人混み・信号待ちを見込んだゆっくりめ）で計算して切り上げ | 人によって大きく違う。目安 |
| 絵地図 | 位置関係をつかむための手描きの絵。縮尺・形は正確でない | 現地の地図の代わりにはならない |

画面には、上部に「**目安です。**地下・屋根のある道を公式の地図から手で拾いました。建物の影・季節・時刻は計算していません。」と常に出す。

### 3.1 作者が確かめること（データの正確さを上げるため）
| No | 確かめること | 方法 | 関係する区間 |
|---|---|---|---|
| D1 | 各区間の距離 | 現地を歩いて歩数・時間を測る、または地理院地図などで線を引いて測る | 全12区間 |
| D2 | 西口の地下歩道（都庁へ向かう道）が都庁まで地下でつながっているか、地上に出る所がないか | 現地 | 都庁–西口地下歩道、西口地下歩道–西口 |
| D3 | 東西自由通路の通れる時間（終日か） | JR の案内・現地の掲示 | 西口–東口 |
| D4 | メトロプロムナード・サブナードの通れる時間と、閉まる出口 | 東京メトロ・サブナードの案内、現地の掲示 | 東口–メトロ、メトロ–サブナード、サブナード–15B出口、メトロ–三丁目 |
| D5 | 15B 出口から区役所までの地上の距離と、屋根の有無 | 現地 | 15B出口–区役所 |
| D6 | 地上の道で、ビル・街路樹・アーケードの影が長く続く所 | 夏の 9時・12時・15時に現地で写真を撮る | 地上の5区間 |
| D7 | 新宿ターミナルマップの新しい版が出ていないか、出口の番号・名前が変わっていないか | 新宿区のサイト | 全区間 |
| D8 | 階段だけの所・エレベーターがある所 | 「エレベーター・階段マップ」（新宿区） | 全区間（今は扱っていない） |

確かめたら `src/cities/shinjuku.ts` の距離・種類・根拠・`checkedOn`・`version` を直し、`npm test` を通す（データの形の検査 `validateCity` が自動で走る）。

## 4. 機能要件

### F1 出発と到着を選ぶ
- F1-1 出発と到着を、選べる5か所から選ぶ。初期値は「新宿駅 西口」→「新宿区役所」。
- F1-2 出発と同じ場所を到着に選んだら（逆も）、2つを入れかえる。
- F1-3 「入れかえ」ボタンで出発と到着を入れかえる。

### F2 2つの道をくらべる
- F2-1 「日陰の道」と「近い道」を横に並べ（狭い画面では縦）、それぞれ **日なたの時間（大きく）・歩く時間・日陰の割合** を出す。
- F2-2 道の帯（日陰＝水色、日なた＝オレンジのしま模様）を、区間の長さに比例して出す。色が見分けにくい人のため、日なたはしま模様にする。
- F2-3 くらべた結果を1文で出す（例「日陰の道にすると、日なたが約7分へります。歩くのは約1分のびます。」）。
- F2-4 2つが同じ道なら札を1枚にし、「いちばん近い道がそのまま日陰の道です」と出す。
- F2-5 札を押すと、その道を絵地図と歩き方に出す。初期値は日陰の道。

### F3 絵地図
- F3-1 外部の地図を使わず、手描きの絵地図（SVG）に、選んだ道を太線（日陰＝水色、日なた＝オレンジ＋太陽の印）で、もう1つの道を点線で出す。
- F3-2 出発・到着の印、選べる5か所の絵と名前、線路・大通り・公園を目印として描く。
- F3-3 画面読み上げ用に、道の中身（区間の種類と距離）を文で付ける。

### F4 歩き方
- F4-1 区間ごとに、種類（地下・屋根の下・地上）・距離・分・案内文・次の目印を出す。
- F4-2 開いている時間に注意が要る区間には注意書きを出す。

### F5 データについて
- F5-1 §3 の内容を短く出す（日陰とした道・日なたとした道・季節と時刻・歩く時間・使える場所）。
- F5-2 「道ごとの根拠を見る」で12区間の種類・距離・根拠と、出典（公式の資料へのリンク）・確かめた日・データ版を出す。
- F5-3 「現地の案内を優先」「熱中症を防げることは約束できない」を出す。

### F6 保存と再開
- F6-1 出発・到着・地図に出す道を端末に保存し、次に開いたとき復元する。
- F6-2 前の版の URL（`#from=..&to=..&mode=..`）で開かれたら、その内容を使う。
- F6-3 保存できない環境でも使える。そのときは一言伝える。

### F7 電波が弱い所でも使える
- F7-1 一度開いた端末では、オフライン（地下で電波が弱いときなど）でも開いて使える。
- F7-2 ホーム画面に追加でき、アプリのアイコンが表示される。

## 5. 道さがしの決まり（`src/router.ts`、純関数）
| 道 | 選び方 |
|---|---|
| 近い道 | 距離の合計がいちばん短い道 |
| 日陰の道 | 「日陰の距離 ＋ 日なたの距離 × 5」がいちばん小さい道（日なた 1m を 5m の遠回りと同じに見る） |
| 同じ重みのとき | 区間の数が少ない方、さらに同じならデータ順で早い方 |

- 日陰の割合 ＝ 日陰の距離 ÷ 全体の距離（％、切り捨て）。日なたが 1m でもあれば 100% と出さない。
- 分 ＝ 距離 ÷ 60 の切り上げ。日なたの分も同じ。

## 6. 非機能要件
| 区分 | 要件 |
|---|---|
| 対応環境 | iOS Safari 16以上、Android Chrome 最新、PC の Chrome / Safari / Edge 最新 |
| 画面幅 | 320px〜1440px で崩れない。主は 390px。PC（960px〜）は左に選ぶ・くらべる、右に絵地図 |
| 速さ | 初回表示 2秒以内、操作の反映 0.1秒以内 |
| 使いやすさ | 押せるものは 44×44px 以上。選ぶ欄の文字は 16px 以上。本文は 16px 以上 |
| アクセシビリティ | WCAG 2.2 AA。コントラスト 4.5:1 以上。キーボードだけで全操作可能 |
| 個人情報 | 位置情報を使わない。選んだ場所は端末内だけに保存し、外部に送らない。アクセス解析なし |
| 通信 | 外部への通信 0 件（公開版は CSP で禁止）。出典のリンクは押したときだけ開く |
| 見た目 | 夏の涼しさ（白・水色・木陰の緑）。日なたはオレンジ。ダークモード対応 |

## 7. 受け入れ基準
| No | 確認すること | 合格の条件 |
|---|---|---|
| AC-01 | 一目で比べられる | 初めての人が、説明なしで「西口→区役所で、日陰の道だと日なたが何分へるか」を **20秒以内** に答えられる（3人で確認） |
| AC-02 | 道が正しくつながる | 自動テストで、ランダムな街 3,000 個の全組で、道が出発地と目的地をつなぎ、最短・日陰それぞれで最小の重みになる |
| AC-03 | 数が正しい | 日陰の割合が 0〜100 の整数、日陰＋日なた＝全体、日陰の道の日なた ≦ 近い道の日なた、が全件で成り立つ |
| AC-04 | 限界が伝わる | 「目安です」が画面上部に常に出る。季節・時刻を考えていないことが「データについて」に書かれている |
| AC-05 | データの根拠 | 12区間すべてに根拠と出典があり、画面で見られる |
| AC-06 | 端末 | iPhone 実機（Safari）と Android 実機（Chrome）で全操作ができる |
| AC-07 | オフライン | 機内モードで開いて道をくらべられる |
| AC-08 | アクセシビリティ | axe で違反 0 件 |
| AC-09 | 画面 | 320 / 390 / 768 / 1280px、ライト / ダークで崩れ・重なり・はみ出し 0 件 |
| AC-10 | 個人情報 | 外部への通信 0 件 |
