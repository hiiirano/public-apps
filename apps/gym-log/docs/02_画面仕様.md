# 筋トレ記録 GYM LOG — 画面仕様書

| 項目 | 内容 |
|---|---|
| 版 | 1.0 |
| 作成日 | 2026-10-23 |
| 対応する要件 | 01_要件定義.md 1.0 |

画面は4つ（記録・履歴・種目・設定）。スマホ（〜959px）は1列で、切り替えは画面下に固定。PC（960px〜）は切り替えを上部に置き、左に主な内容、右に「今週」の札を固定表示する。

## 1. 画面の並び

| 画面 | 状態 | 左（スマホでは上） | 右（スマホでは下） |
|---|---|---|---|
| 記録 | 始める前 | 今日のおすすめ（絵・始めるボタン3つ）・見本で試す（記録が空のとき） | 今週・最近の記録3件 |
| 記録 | 記録中 | 記録中の帯（固定）・種目の札・種目を追加・種目選び | 今週 |
| 記録 | 終わった直後 | おつかれさまでした・種目ごとの結果・閉じる／続きを記録する | 今週 |
| 履歴 | — | 日ごとの札（開くと中身と「消す」） | — |
| 種目 | 一覧 | 種目を作る・部位でしぼる・絵の一覧・隠した種目 | — |
| 種目 | 1つの種目 | 絵・自己ベスト・伸びのグラフ | 最近の記録・名前などを変える・隠す |
| 設定 | — | 画面の色・記録中の画面・バックアップ・記録を消す／試す・このアプリについて | — |

## 2. 区画ごとの部品

### 今日のおすすめ
| 部品 | 仕様 |
|---|---|
| 見出し | 「上半身の日」「下半身の日」「休む日」（1.9rem）と理由（例「上半身は5日あいています（前回 10/18）」） |
| 絵 | おすすめの種目を最大4つ、絵と名前で |
| ボタン | 「おすすめで始める」（ライム・高さ64px。休む日は「それでもやる」）／「前回と同じ種目で始める」（前回があるとき）／「種目を選んで始める」 |

### 今週（常に暗い札）
| 部品 | 仕様 |
|---|---|
| 数字 | 今週やった日・続けている週・今週の総重量（Oswald 最大 2.6rem） |
| 曜日 | 月〜日の丸。やった日はライムに✓、今日は白い輪 |
| ひとこと | 「前回から3日。このペースで続けましょう。」など |

### 記録中の帯（画面上に固定）
記録中の印・経過分・セット数・休けい時間（前のセットから）・「終わる」。400px 以下では「記録中」の文字とセット数を省く。

### 種目の札
| 部品 | 仕様 |
|---|---|
| 頭 | 絵（96px）・名前・部位と器具・「前回 10/20（火） 55kg×10 / 55kg×10」・外すボタン（ごみ箱） |
| 記録したセット | 番号・「60kg × 10回」（数字 1.6rem）・印（自己ベスト＝ライム／前回より上＝淡いライム／前回と同じ＝灰）・消すボタン |
| 入力 | 「3セット目」・重さ（−・数字・＋）・回数（−・数字・＋）。600px 以上は重さと回数を横に並べる |
| 見通し | 「前回の3セット目 55kg×8」と、いまの数で記録した場合の判定（自己ベスト！／前回より上／前回と同じ） |
| 記録ボタン | 「✓ 3セット目を記録」（ライム・高さ60px）。回数が0なら記録せず「回数を入れてください」 |

### 種目選び
部位のチップ（すべて・胸・背中・肩・腕・お腹・脚・有酸素。横にスクロール）と、絵の札の一覧（スマホ2列、広い画面は自動）。追加ずみの札は「✓ 追加ずみ」と縁取り。押すとその種目へ移動して重さの欄にカーソル。

### 終わった直後
暗い札に日付・「おつかれさまでした」・分・セット・総重量・「自己ベスト ○回・前回より伸びた種目 ○つ」。その下に種目ごとに絵・セット数・印（自己ベスト／前回より +○kg／はじめて）。減った数は出さない。

### 履歴
日付（Oswald 1.6rem）と曜日・種目の絵（最大5つ）・時間・セット数・総重量。押すと開いて、種目ごとのセットと「この日の記録を消す」。

### 種目の詳しい画面
絵（168px）・名前・部位/器具/記録のしかた・自己ベスト・伸びのグラフ（重さの種目は日ごとの最高の重さ。2回未満は案内文）・最近の記録5回・「名前などを変える」「使わないので隠す」。最初からある種目は名前と重さの刻みだけ変えられる。

### お知らせ
画面下（切り替えの上）に出る。普通は3.5秒、「元に戻す」付きは8秒。自己ベストのときはライム地。

### 状態
| 状態 | 表示 |
|---|---|
| 記録が空 | おすすめは「まずは上半身から」。見本で試すボタン。履歴は「まだ記録がありません」 |
| 保存できない環境 | 下部に「この画面では保存できないため、閉じると記録が消えます。」 |
| 入力の誤り | 数字の欄の枠を赤に（aria-invalid）。欄を離れると範囲内に直す |
| 種目名が空・重複 | 「名前を入れてください。」「同じ名前の種目があります。」 |
| 読み込めないファイル | 「読み込めませんでした。このアプリで書き出したファイルを選んでください」 |
| 読み込みの確認 | 「○回分の記録を読み込みます。いまの記録は置きかわります。」読み込む／やめる |
| すべて消す | 2段階（「すべての記録を消す」→「すべて消す」／やめる） |

## 4. 保存する内容
localStorage のキー `gym-log.v2` に、`{ v: 2, exercises, workouts, settings }` を保存する。

| 項目 | 中身 |
|---|---|
| exercises | id・名前・部位・器具・記録のしかた・重さの刻み・絵・隠したか・自作か |
| workouts | id・日付・開始・終了（記録中は null）・種目ごとのセット（重さ・回数/秒/分） |
| settings | 画面の色・画面を消さない |

読み込み時に形と範囲（名前24文字、重さ0〜500、セット50まで、種目30まで、記録中は1つまで など）を検査し、合わなければ初期状態にする。キーがなく前の版（`gymlog.*.v1`）があれば移す。
