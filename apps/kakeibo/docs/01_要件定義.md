## 1. 目的
毎日の支出を **金額 → 費目 → 書きこむ の3手** で残し、**「このままだと月末いくらになるか」を月の途中で一目で見せて、使いすぎを先回りで止める**。

### 1.1 想定する場面
- 10月23日、夜。今月の予算は13万円。スマホを開くと「このままだと月末 ¥146,130。予算を ¥16,130 こえます」と赤字で出る。残り9日を「1日 ¥161」でしのぐと決める。
- レジの後、1,200円・外食を3手で書く。5秒以内。
- 機種変更。古いスマホで「バックアップを書き出す」、新しいスマホで「ファイルを読み込む」。

### 1.2 やらないこと
- 銀行・カードとの連携、レシートの読み取り、AI による自動分類（API キーが要るため。前の版の AI 連携は削除）
- 収入・貯金の管理、費目ごとの予算（まずは月の予算1つに絞る）
- 会員登録・サーバーへの送信・家族での共有

## 2. 利用者
| 利用者 | 特徴 | 求めること |
|---|---|---|
| 一人暮らし・共働きの人（主） | ITに詳しくない。レジの後や寝る前に片手で書く | 迷わず3手で書ける。月末の着地が一目で分かる |
| 家計を見直したい人（従） | 月末にふりかえる | 費目ごとの合計と、前の月の結果が見られる |

## 3. 機能要件

### F1 書きこむ
- F1-1 金額は 1〜99,999,999円の整数。数字キーボードが開く。全角・カンマ・「円」「¥」付きも読む。
- F1-2 費目は絵つきの9つから選ぶ: 食費・外食・日用品・住まい・交通・趣味・交際・医療・その他。
- F1-3 「書きこむ」で保存。金額の欄で Enter を押しても保存できる。保存後は金額と費目が空になり、金額の欄にカーソルが戻る。
- F1-4 日付とメモは「日付・メモ」を開いたときだけ（初期値は今日。表示中の月が今月でなければその月の1日）。メモは40文字まで。
- F1-5 金額なし・数字以外・0円・上限超え・費目なし・日付なしは、理由を欄の下に出して保存しない。
- F1-6 書いた記録は「直す」「消す」ができる。書く・直す・消すは、すぐ「元に戻す」ができる。

### F2 月の切り替え
- F2-1 画面上部の1か所（‹ 2026年10月 ›）だけで月を切り替え、ペース・費目ごと・記録・予算がすべてその月になる。
- F2-2 今月以外を見ているときは「今月へ」を出す。

### F3 今月のペース（先回り警告）
- F3-1 大きな字で「このままだと月末 ¥○」を出す。
- F3-2 見込み = 住まい（月1回の支払い）と今日より先の日付の記録はそのまま ＋ それ以外の今日までの合計 ÷ 経過日数 × 月の日数。うるう年の2月は29日で数える。
- F3-3 予算があるとき、4段階で判定して色と文で知らせる: 収まる（緑）／ぎりぎり＝予算の9割をこえそう（黄）／このままだとこえる（朱）／もうこえた（朱）。
- F3-4 図: 1日からの累計（実線）、今日から月末への見込み（点線）、予算の線、予算どおりに使うときの斜めの線。こえそうなときは予算より上を薄い朱にする。
- F3-5 「残り○日（今日をふくむ）。1日 ¥○ までなら予算に収まります」を出す。
- F3-6 月の1〜4日目は「見込みが大きくぶれます」と添える。
- F3-7 過去の月は「この月の合計」と予算との差、先の月は書いた分（予定）だけを出す。

### F4 費目ごと
- F4-1 その月の費目ごとの合計・件数・割合を、多い順に絵と横棒で出す。

### F5 記録の一覧
- F5-1 その月の記録を、日ごと（新しい日が上）にまとめ、日ごとの合計を出す。

### F6 予算
- F6-1 「1か月の予算」を決めると、その月から先の月に引き継ぐ。空にするとその月から予算なし。
- F6-2 引き継いでいるときは、どの月に決めた予算かを出す。

### F7 書き出し・読み込み（端末の引っ越し）
- F7-1 全部の記録と予算を JSON（バックアップ）で書き出す。
- F7-2 全部の記録を CSV（表計算用。Excel で文字化けしない BOM 付き、日付・金額・費目・メモ・id）で書き出す。
- F7-3 JSON / CSV を読み込んで、今の記録に足す。同じ id の記録はとばし、id のない CSV の行は日付・金額・費目・メモが全部同じ記録があればとばす。同じファイルを2回読んでも増えない。
- F7-4 前の版（v1）の JSON / CSV も読める（4分類はメモの頭に残し、費目は「その他」）。
- F7-5 読み込みの結果（足した数・とばした数）を知らせ、「元に戻す」で取り消せる。

### F8 保存
- F8-1 記録と予算を端末に保存し、次に開いたとき復元する。
- F8-2 前の版の保存内容は自動で引き継ぐ。前の版で保存した API キーは消す。
- F8-3 保存内容が壊れていたら初期状態で開き、元のデータは別のキーに取っておく。1件ずつの不正はその件だけのぞく。
- F8-4 保存できない環境でも書けて、「閉じると消えます」と知らせる。
- F8-5 「全部消す」は確かめてから消し、「元に戻す」で戻せる。

### F9 オフライン
- F9-1 一度開いた端末では、通信なしで開いて書ける。ホーム画面に追加できる。

## 4. 非機能要件
| 区分 | 要件 |
|---|---|
| 対応環境 | iOS Safari 16以上、Android Chrome 最新、PC の Chrome / Safari / Edge 最新 |
| 画面幅 | 320px〜1440px で崩れない。PC（960px〜）は2列 |
| 速さ | 初回表示 2秒以内（スマホ回線）、書きこみの反映 0.1秒以内 |
| 使いやすさ | 押せるものは 44×44px 以上、入力欄の文字は 16px 以上、本文 16px 以上 |
| アクセシビリティ | WCAG 2.2 AA。コントラスト 4.5:1 以上。キーボードだけで全操作できる。図には文での説明を付ける |
| 個人情報 | 記録は端末内だけ。外部への通信 0 件。アクセス解析なし |
| 安全 | メモは必ず無害化して表示。公開版は CSP で外部の読み込み・接続を禁止。CSV の書き出しは式として動かないよう対策 |
| 計算の正しさ | すべて整数の円。1件 1億円未満 × 2万件でも誤差なし |
| 見た目 | 紙のノート・手帳（生成りの紙＋インクの紺、罫線、明朝の見出し）。割り勘アプリと別物に見えること。ダークモード対応 |

## 5. 受け入れ基準
| No | 確認すること | 合格の条件 |
|---|---|---|
| AC-01 | すぐ書ける | 初めての人が説明なしで、1,200円・外食を **10秒以内** に書ける（3人） |
| AC-02 | 見込みが正しい | 単体テストで、月初・月末・うるう年・支出0・大きな額・過去/先の月の境界と、ランダム 5,000 件の性質がすべて合格 |
| AC-03 | 一目で分かる | 画面を見せて5秒で「このままだと月末いくら・予算をこえるか」を言える（3人） |
| AC-04 | 入力の揺れ | 全角・カンマ・円・空・0・上限超え・文字で、落ちずに正しく扱う |
| AC-05 | 引っ越し | 書き出した JSON / CSV を別の端末で読み込むと、同じ記録と予算になる。2回読んでも増えない |
| AC-06 | 端末 | iPhone（Safari）と Android（Chrome）の実機で全操作ができる |
| AC-07 | オフライン | 機内モードで開いて書ける |
| AC-08 | アクセシビリティ | axe で違反 0 件。キーボードだけで書ける |
| AC-09 | 画面 | 320 / 390 / 768 / 1280px × ライト / ダークで崩れ・重なり・はみ出し 0 件 |
| AC-10 | 個人情報 | 外部への通信 0 件。API キーの入力欄がない |
