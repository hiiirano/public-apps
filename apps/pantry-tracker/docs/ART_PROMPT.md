## 2. ChatGPT に渡すプロンプト

```
北欧キッチン風の、やさしい食材アイコンのシートを1枚描いてください。

画風:
- 少し立体感のあるフラットなイラスト。輪郭線は細く、角は丸く、影はごく淡く1方向だけ。
- 色は自然でやや落ち着いた色（彩度は控えめ）。背景は無地の白。
- すべて正面か斜め上から見た、同じ大きさ・同じ明るさの単体のアイコン。文字やラベルは入れない。
- 白・淡い青緑（#e0efec）・木の色（#c99b6b）の画面に置くので、それらになじむ色合いに。

並べ方: 6列 × 6行の格子。各マスの中央に1つずつ、マスどうしの間をあけて描く。

描く物（左上から右へ順に）:
牛乳の紙パック、卵、骨付き鶏もも肉、豚の薄切り肉、牛ステーキ肉、魚の切り身、
チーズ、バター、キャベツ、トマト、きゅうり、にんじん、
ブロッコリー、しめじ、なす、りんご、いちご、レモン、
ジュースの紙パック、茶わんのごはん、えび、カップのアイス、どんぶりのめん、食パン、
たまねぎ、じゃがいも、バナナ、缶詰、おにぎり、四角い保存容器（豆腐・作りおき）、
湯のみのお茶、お皿とフォーク、買い物かご
```

## 3. 取り込み方
1. シートから1つずつ切り出し、背景の白を透明にする。
2. 128×128 の webp にする（例: `magick in.png -resize 128x128 -quality 82 public/art/milk.webp`）。
3. `public/art/LICENSES.md` の出典を「ChatGPT（OpenAI）の画像生成で作成」に書き換え、`FLUENT-EMOJI-LICENSE.txt` を消す。
4. `npm run build` → `npm run test:e2e` で、オフラインでも絵が出ることを確かめる。
