## v2.0.0（2026-10-23）
「使いすぎを月の途中で先回り」する家計簿として、見た目と入力から作り直した。

### できること
- 金額 → 絵つきの費目（9つ）→ 書きこむ の3手で記録。日付とメモは必要なときだけ
- 「このままだと月末 ¥○」を大きく表示し、予算に対して 収まる／ぎりぎり／こえそう／こえた を色と文で知らせる
- 累計・見込み・予算・予算どおりのペースを1枚の図で
- 「残り○日。1日 ¥○ までなら収まります」
- 費目ごとの合計と割合、日ごとの記録（直す・消す・元に戻す）
- 月の切り替えは画面上部の1か所。過去の月はふりかえり、先の月は予定
- 月の予算を決めると、先の月にも引き継ぐ
- JSON（バックアップ）と CSV（表計算用）の書き出し・読み込み。同じ記録は二重にならない
- 一度開けばオフラインでも使える。ホーム画面に追加できる

### 前の版（v0.1）から変わったこと
- 見た目を紙のノート・手帳風に（生成りの紙・インクの紺・罫線・明朝）。割り勘アプリと別物にした
- AI 連携（API キーの入力）を削除。前の版で保存した API キーは、開いたときに消す
- 4分類（必需・娯楽・文化・予備）をやめ、費目9つに。前の版の記録は「その他」にして、元の分類をメモの頭に残す
- 収入・貯金目標・4分類ごとの予算をやめ、月の予算1つに。前の版の予算は「収入 − 貯金目標」で引き継ぐ
- 見込みで家賃などの「住まい」をのばさないようにした（月初に大きく外れていた）
- 取り込みは「置き換え」から「足す」に。CSV も全部の月を書き出し、読み込めるように
- 確認窓・警告窓をやめ、画面内の確認と「元に戻す」に
- 外部への通信 0 件（CSP で禁止）。書体を画面の文字だけに絞って同梱
- 保存形式を v2（`kakeibo.notebook.v2`）に。前の版の保存内容は自動で引き継ぐ

### 既知の問題・制限
- 費目を自分で足す・名前を変えることはできない。費目ごとの予算もない
- 見込みは「今までのペースが続く」前提の単純な計算。月の後半にまとまった出費がある月は外れる（先の日付で書けば見込みに入る）
- メモの漢字など、同梱書体にない文字は端末の書体で表示される
- 費目の絵は仮（Microsoft Fluent Emoji）。専用の絵への差し替えは docs/ART_PROMPT.md
- 更新は、すでに開いたことのある端末では次に開いたときに反映される（オフライン対応のため）
- 実機（iPhone・Android）での確認と利用者テストは未実施（テスト計画書 §4・§5）
