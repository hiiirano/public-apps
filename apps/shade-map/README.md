# 日陰MAP 新宿β

新宿の公共地下通路・屋根付き区間を使い、プリセット地点間の「最短」と「日差し回避」を比較する固定データ型の静的Webアプリです。

## 開発

```bash
npm install
npm test
npm run dev
npm run build
```

## データの考え方

- 2025年11月版の新宿区公式ターミナルマップ等を2026年8月23日に目視確認
- 測量データではなく、1日で利用価値を検証するための小さな手動グラフ
- 屋内・屋根あり区間だけを確定扱いし、建物影はまだ推定しない
- 営業時間、工事、臨時閉鎖には追従しないため、現地表示を優先

主な出典はアプリ内と `src/cities/shinjuku.ts` に記載しています。

## プライバシー

サーバー、ログイン、広告、トラッカー、位置情報取得はありません。選んだ出発地・目的地・モードはURL fragmentにのみ保存され、外部送信しません。
