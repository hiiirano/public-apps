# その場の割り勘 — 画面仕様書

| 項目 | 内容 |
|---|---|
| 版 | 1.0 |
| 作成日 | 2026-10-22 |
| 対応する要件 | 01_要件定義.md 1.0 |

1画面で完結する。スマホ（〜959px）は縦1列、PC（960px〜）は左に入力、右に結果を固定表示する。

## 1. 画面の並び

| 順 | 区画 | スマホ | PC |
|---|---|---|---|
| 0 | 上部（題・説明・テーブルの絵） | 1列 | 文と絵を横並び |
| 1 | ① お会計の金額 | ↓ | 左列 |
| 2 | ② だれと割る？（人数・1人ずつ・割合） | ↓ | 左列 |
| 3 | ③ みんなの支払い（結果） | ↓ | 右列（スクロールしても見える） |
| 4 | 端数の設定 | ↓ | 左列 |
| 5 | 下部（新しい会計・メンバーも消す・注記） | ↓ | 中央 |
| — | 画面下の帯（結果の要約と「結果を見る」） | 結果が画面に見えていないときだけ | 出さない |
| — | お知らせ（コピー・削除の取り消し） | 画面下に一時表示 | 同じ |

使う頻度の低い「端数の設定」は結果の下に置き、金額→人数→結果の順に、上から迷わず進めるようにした。

## 2. 区画ごとの部品

### ① お会計の金額
| 部品 | 仕様 |
|---|---|
| 入力欄「伝票の合計」 | 文字 2.2rem・高さ 72px。数字キーボード（inputmode=numeric）。全角・カンマ・「円」「¥」付きも読む |
| 表示 | 入力中は数字のまま。欄を離れると 3 桁区切りにする（入力中に区切るとカーソル位置がずれるため。要件 F1-3 からの変更） |
| 注意 | 数字以外:「数字だけで入れてください（例: 12800）。」／上限超え:「9,999,999円までです。」。欄の枠を赤にし、結果は直前の正しい値のまま |

### ② だれと割る？
| 部品 | 仕様 |
|---|---|
| 人数 | 「−」「＋」（56px の丸ボタン）と、人数の直接入力。2〜30人に収める。範囲外の数は端に寄せる |
| 1人ずつの札 | 顔の絵・名前欄（20文字まで、空なら「n人目」）・外すボタン |
| 払い方 | 「おごり」「少なめ」「ふつう」「多め」の4択。各ボタンに倍率（×0.8 など）を併記。選ぶと金額指定は解除 |
| 幹事 | 「幹事にする」を押すと、その人が「幹事（集める人）」になり、札の地がオレンジになる。幹事は常に1人 |
| 金額を指定 | 押すと「この人は ___ 円」の欄が開く。「指定をやめる」で傾斜に戻る。指定中は4択を薄く表示 |
| 外す | 2人のときは押せない。外すと「元に戻す」付きのお知らせを8秒出す |
| 顔の割り当て | 使われていない顔を若い番号から。12人までは重ならない |
| 割合を変える | 幅いっぱいのボタン（高さ 56px）。開くと「少なめ」「多め」の倍率を 0.1 刻みで変えられる（少なめ 0.1〜0.9、多め 1.1〜3.0）。「はじめの割合に戻す」付き |

### ③ みんなの支払い
| 状態 | 表示 |
|---|---|
| 金額が空・0 | 「お会計の金額を入れると、ここに1人ずつの金額が出ます。」 |
| 計算できない | 理由と直し方を赤枠で（全員おごり／指定額が会計を超える／残りを払う人がいない） |
| 計算できた | 1人ずつ: 顔・名前・札（幹事・自分の分／少なめ ×0.8／おごり／金額指定）・金額（1.5rem）。差額（「幹事のおつり ○円」「幹事が ○円 足す」「ぴったり」）。内訳4行（お会計／集める合計／幹事が受け取る／幹事が実際に出す額）。「LINEで送る文をコピー」、共有機能がある端末では「共有」。「送る文を見る」で文を表示 |

- 入力のたびにすぐ計算し直す（計算ボタンはない）。
- 画面読み上げには、入力が 1.2 秒止まってから「7人で29,000円を集めます。幹事のおつり 400円。」とだけ伝える。
- コピーに失敗したら、そう伝えて「送る文を見る」を開く。

### 端数の設定
| 部品 | 仕様 |
|---|---|
| 集める単位 | 1円／10円／100円／500円／千円（初期値 100円） |
| 端数の扱い | 「多めに集める（幹事におつりが出る）」／「少なめに集める（足りない分は幹事が出す）」（初期値 多め） |

### 下部
| 部品 | 仕様 |
|---|---|
| 新しい会計 | 金額と金額指定だけを消す。メンバー・名前・幹事・割合は残す |
| メンバーも消す | 4人の初期状態に戻す（割合・端数の設定は残す）。「元に戻す」付き |
| 注記 | 入力はこのスマホ（ブラウザ）の中にだけ残り、外に送らないこと（「キャッシュと同じ」と言い換えて伝える）、ほかのアプリへのリンク。素材の権利表記は画面に出さず、`art/LICENSES.md`・`art/TABLER-LICENSE.txt` として同梱する（MIT は配布物への同梱で足りる） |
| 保存できない環境 | 「この画面では保存できないため、閉じると入力が消えます（計算はできます）。」 |

## 4. 保存する内容
端末の localStorage（キー `warikan.on-the-spot.v3`）に、金額・メンバー（id・名前・払い方・指定額・顔）・幹事・割合・単位・端数の扱いを保存する。読み込み時に形と範囲を検査し、壊れていれば初期状態にする。
