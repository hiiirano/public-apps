# ヒエヒエ冷蔵庫

最初はプリン・ケーキ・アイスを段ごとに揃える3×3整理パズルとして始まり、クリア直後に説明なしの4人から持ち主を選ばされる短時間の理不尽ミニゲームです。候補が手に持っている物は手掛かりに見えますが、正解とは一切関係ありません。

## 1ラウンド

1. 3×3盤面で任意の2マスを交換し、同じスイーツを段ごとに揃える
2. `CLEAR!` の直後、突然「この冷蔵庫の持ち主は誰？」と聞かれる
3. 冷蔵庫と候補の持ち物を観察し、7人の候補母数から抽選された4人を選ぶ
4. 約1秒の間の後、根拠のない正解と「持ち物は関係ない」が発表される
5. 同じ問題と自分の回答を含むURLを友達へ送る
6. 友達の回答後、正解・自分・送信者の選択を比較する

ログイン・通信・サーバーは不要です。問題ID、seed、キャラ順、送信者の選択位置はURL fragmentで保持し、破損したURLは新規ラウンドへ戻ります。ゲーム判定と共有URL処理は `src/game.ts` の純関数へ分離しています。
