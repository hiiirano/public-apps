# アプリ判定プロンプト（Gemini / agy 用）

使い方: public-apps のフォルダで `agy` を起動し、下のコードブロックを貼る。
結果は `deploy/REVIEW_<日付>.md` に書き出させる。

```text
あなたはスマホアプリの品質レビュアーです。このリポジトリの apps/ 以下にある9本のWebアプリを、
実際にブラウザ（スマホ幅 390x844）で触って判定してください。公開版は https://hiiirano.github.io/public-apps/<slug>/ です。
一覧と一言説明は deploy/apps.json にあります。

## 想定する利用者
ITリテラシーが高くない一般の人。説明を読まずに触る。

## 各アプリでやること
1. 開いて、説明を読まずに「このアプリで何ができるか」が30秒以内に分かるか試す
2. 主な使い方を最後まで1回通す（入力 → 結果が出る → 保存や共有があればそれも）
3. 途中で詰まった・壊れた・意味が分からなかった箇所を、手順つきで記録する
4. スマホ幅での表示崩れ、文字の小ささ、押しにくいボタンを記録する

## 判定（各アプリに1つ）
- 載せる: 今のまま知らない人に見せてよい
- 直せば載る: 直す点が3つ以内で、それぞれ半日以内で直せる
- しまう: 根本的に弱い／似たアプリが世の中に多く、直しても選ばれる理由がない

## 出力（deploy/REVIEW_<YYYYMMDD>.md に書く）
- 冒頭に9本の判定一覧表（slug・判定・一言理由）
- アプリごとに: 30秒で分かったか / 通しで使えたか / 問題点（再現手順つき・重要度 高中低）/ 直すならこの3つ
- 最後に「1本だけ磨くならどれか」とその理由
- 推測と実際に触って確かめたことを分けて書く。コードは変更しない。
```
