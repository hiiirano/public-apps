## 2. 区画ごとの部品

### 1 わが家の条件
| 部品 | 仕様 |
|---|---|
| 何人分？ | 大人・子どもそれぞれ「−」「＋」（48px の丸ボタン）と人数。大人 1〜10、子ども 0〜10。注記「子どもは大人の半分の量で計算します。」 |
| 作る食事 | 絵つきの4択（晩ごはんだけ＝月／朝と晩＝朝日・月／昼と晩＝太陽・月／朝・昼・晩）。2列。注記「朝は主食＋おかず1品、昼は1品（＋汁物）、晩は主菜・副菜・汁物。」 |
| 好きなジャンル | 絵つきの4択（おまかせ／和食多め／洋食多め／中華多め）。2列。下に選び方の説明（例「和食を7日のうち4日、洋食と中華を合わせて3日にします。」） |
| 食物アレルギー（外す） | 9品目のチップ（チェックで赤い地）。注記「しょうゆ・ルウ・ハムなどの加工品も含めて、少しでも疑わしい料理は外します。…ほかのアレルギーは、下の「苦手なもの」に入れると外せます。」 |
| 苦手なもの（外す） | 絵つきボタン16種（押すと赤い地・×印・絵を薄く）。「ほかに外したいもの」入力欄＋「追加」。選んだ言葉の一覧: 言葉・「牛こま切れ肉・合いびき肉を使う 11品を外します」・注意（例「玉ねぎは外れません」）・× ボタン |
| 冷蔵庫の残り（使う） | 絵つきボタン12種（押すと緑の地・✓印）。「ほかに使いたいもの」入力欄＋「追加」。一覧: 言葉・「月・木曜日で使います（焼きうどん、…）」（2食以上のときは「月(朝)・木(晩)」）または赤字で「この献立の料理では使いません」「朝食・昼食を作ると使えます（上の「作る食事」）」「使う料理がほかの条件で外れています」「今週は使えませんでした」・× ボタン |
| 品数と時間 | スイッチ3つ: 副菜をつける（晩）（初期 ON）／汁物をつける（昼・晩）（初期 ON）／20分以内の料理だけ（初期 OFF） |

- 自由入力は「、」「,」空白・改行で区切って複数入れられる。Enter（変換中は除く）でも追加。同じ意味の言葉（ネギ／ねぎ／長葱）は1つにまとめる。
- 入力欄に入れた言葉に対応するボタンがあれば、そのボタンも押された状態になる。

### 2 今週の献立
| 部品 | 仕様 |
|---|---|
| 見出しの道具 | 「別の組み合わせ」（週全体を作り直す）、「すべて閉じる／すべて開く」 |
| 注意（あれば） | 黄色の枠: 主菜がない／主菜が重なった／「多め」が4日にできなかった／副菜がない |
| 週の帯 | 7マス。曜日・夕食の主菜の絵・夕食のジャンルの色（和=緑、洋=赤、中=黄）。下に「和食 3日　洋食 2日　中華 2日 ／ 朝食・昼食・夕食 21食 ／ 夕食の主菜が20分以内の日 3日 ／ 残り物 2/3品を使用」。補足（汁物を付けなかった理由・朝昼の候補が少ないなど） |
| 日の札 | 上の線が夕食のジャンルの色。曜日の丸・「月曜日」・「晩は和食」の札 |
| 朝食・昼食・夕食（それぞれ開閉） | 見出しは朝日・太陽・月の絵と「朝食」「昼食」「夕食」（地の色 朝=黄、昼=赤、晩=緑）。閉じると料理の絵と「料理名 ほか1品」。開くと: 1品目（夕食は絵 112px、朝昼は 80px。「主菜・20分」「主食・10分」「1品・15分」・残り物の札）、2品目以降（絵 56px。「副菜」「汁物」「おかず」）、「材料（2.5人前）とアレルギー」（開閉。開くと幅いっぱい）と「朝食を変える」などのボタン |

## 3. 状態
| 状態 | 表示 |
|---|---|
| 初めて開いた | 初期条件（大人2・子ども1・おまかせ・副菜と汁物あり）の献立をすぐ出す |
| 正常 | 7日分の札と買い物リスト |
| 候補なし | 「条件に合う主菜がありません。苦手なものや「20分以内」を見直してください（アレルギーの条件はゆるめません）。」買い物リストは「献立ができると、ここに買うものが出ます。」 |
| 候補が少ない | 同じ主菜が出る旨、「多め」の日数が減った旨を黄色の枠で |
| 保存できない | 下部に赤字「この画面では保存できないため、閉じると条件が元に戻ります（献立は作れます）。」 |
| オフライン | 通常どおり使える |

## 5. 保存する内容
端末の localStorage（キー `meal-planner.v3`）に次を保存する。読み込み時に形と範囲を検査し、壊れていれば初期状態にする。

| 項目 | 内容 | 検査 |
|---|---|---|
| v | 3 | 3 以外は初期状態 |
| input | 大人・子ども・作る食事（mealSet: 晩／朝晩／昼晩／朝昼晩）・ジャンル・アレルギー・苦手・残り物・副菜・汁物・20分以内・組み合わせ番号 | 人数の範囲、作る食事・ジャンル・アレルギーは決まった値だけ（作る食事が無い 1.0 の保存は「晩」として読み、ほかの設定を保つ）、言葉は1〜20文字・30個まで |
| swaps | 「変える」を押した回数。キーは夕食 "1"〜"7"、朝食 "1朝"〜"7朝"、昼食 "1昼"〜"7昼" → 1〜50 | 形の違うキー・範囲外は捨てる |
| checked | 買ったもの（「材料名__単位」） | 文字列 60文字以内・300個まで |

献立そのものは保存せず、条件と番号から毎回同じものを作り直す。前の版のキー（`meal-planner.input` など）は読み込んで引き継いだあと消す。
