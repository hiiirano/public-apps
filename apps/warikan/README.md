# その場の割り勘 warikan

飲み会・食事の会計を、幹事のスマホ1台で計算する静的アプリ。

- 合計金額を入力し、＋1人で人数を追加。名前は任意。
- おごり / 少なめ / ふつう / 多め（初期比率 0 / 0.7 / 1 / 1.3）。設定で変更可能。
- 固定額は傾斜より優先し、切り上げない。残額を比率で分けて切り上げる。
- 現金は100円、PayPayなどは1円が初期値。1 / 10 / 100 / 500円単位を選択可能。
- 集める額には幹事の自分の分を含む。会計との差をおつりまたは追加負担として表示。他の人から受け取る額と幹事の実質負担も表示。
- 全員の負担が0になる設定は不可。全員固定額なら不足を幹事が追加負担。固定額が会計を超えても指定額を維持する。
- LINEに貼る文をコピー。失敗時は選択できるテキストを表示。
- 新しい会計は合計金額だけリセット。端末保存キーは `warikan.on-the-spot.v2`。旧キーは読み書きしない。

## 開発・検証

```sh
npm install
npm run build
npm test
```

計算は `src/warikan.ts` の純粋関数。合計・固定額は0〜999,999,999円、人数1〜100人、比率0〜100。

共通の `apps/_shared/ui.css` を読み込み、アプリ側でオレンジ系テーマを上書き。
素材は `public/art/LICENSES.md` を参照。Fluent Emoji Flat / Tabler Icons（MIT）。
