### T2 で必ず成り立つこと
- 日付（1万件）: d に k 日足して引くと d に戻る。差は k。通し番号の往復で同じ日付。Date を使わない別の計算方法（暦から直接）と通し番号が一致。n か月足すと月の差は n、日は元の日以下で、行き先の月末を超えない
- 時差（3千件、2000〜2150年の任意の瞬間）: UTC の日付は ISO 文字列の先頭、東京の日付は UTC+9 時間の日付と一致
- 期限の色: 日数が増えるほど急ぎ度は下がる（-400〜400日で逆転なし）
- 操作（300通り × 60手）: 在庫の数 + 記録した数 + 記録せずに消した数 = 入れた数。数は常に 1〜99。保存内容の検査に通る。急ぐ物の数 ≦ 全体。置き場所ごとの合計 = 全体
- 壊れた保存内容（3千件）: 正しい内容の1か所をランダムな値に変えても、落ちずに「読まない」か「正しい形で読む」

### 端末の時差の確認
`process.env.TZ` を東京・ニューヨーク・オークランド・キリティマティ（UTC+14）・パゴパゴ（UTC−11）・UTC に切り替え、今日の日付と日数の差が変わらないことを確かめる。

### T3 の主な項目
空のときの案内・3つの置き場所／今日の日付／牛乳ボタンで冷蔵庫に「あと7日」／お知らせに「期限 10/30（金）」／「直す」で開く／「今日」で「今日まで」／「1か月後」で 11/23／保存で閉じる／そろそろ使う物に出る／名前が空の注意／「鶏むね肉」で鶏肉の絵／冷凍庫・×3・「あと2日」／絵を選ぶ／`<b>x</b>` が文字のまま出る／期限なし／使った・捨てた・割合 50%／元に戻す／2つ捨てると「買いすぎかも」／記録せずに消す／日付が 10/25 に変わると「今日まで」、10/26 で「1日すぎ」／再読み込みで残る／書き出したファイルの中身／すべて消す／読み込むと元どおり／違うファイルは読まない／悪意のある id・名前のファイルを読んでも HTML が混ざらず、振り直した id で開ける／ぜんぶ見るで32種／キーボードで入れる・開く・Esc で閉じる／v0.1 の在庫の移しかえ／古い API キーの削除・入力欄がない／壊れた保存内容でも開ける／保存できない環境でも使える／オフライン

## 3. 見つかった不具合と対応

| No | 内容 | 見つけた検査 | 対応 |
|---|---|---|---|
| B1 | 記録の割合の帯が公開版で出ない（CSP が style 属性を禁じるため） | T10 | 帯を SVG の幅の属性で描くように変更 |
| B2 | PC で「家にある物」と記録の間に大きな空白 | T10 | 右側を1つの列にまとめた |
| B3 | ボタンの読み上げ名が見えている文字と違う（WCAG 2.5.3）45 か所 | T5 | aria-label をやめ、見える文字＋読み上げ専用の文字に |
| B4 | 最初に出る12種が冷蔵庫の物ばかりで、パンなどが「ぜんぶ見る」を押さないと出ない | T3 | 最初の12種を冷蔵・冷凍・棚から選んだ並びに |
| B5 | 320px で棚の中が1列になり、縦に長い | T10 | せまい画面では余白を詰めて2列に |
| B6 | 768px で「そろそろ使う物」の1行が縦に長い | T10 | 600〜999px ではボタンを右に並べる |
| B7 | フォントが1つ 143KB と重い | ビルドの出力 | 画面の文字だけに絞り、ヒントを外して 119KB に |
| B8 | 読み込んだファイルの id は長さしか検査せず、HTML の属性に生で入れていた。引用符やタグを含む id で任意の HTML が画面に混ざりうる（重要度: 中） | 外部レビュー（Codex） | id を英数字・`_`・`-` の 1〜64 文字に限り、合わない id・重なる id は新しく振り直す。属性に入れる値はすべて無害化し、セレクタは CSS.escape を通す。単体テスト（危ない id の振り直し・文字種）と、悪意のあるファイルを読み込む E2E を追加 |

v0.1 からの主な問題（作り直しで解消）: AI 連携に API キーが必要だった／保存内容の検査が弱く、壊れたデータで画面が崩れうる／期限の日数を端末時刻の割り算で出していた／書き出し・読み込みがない／使い切った・捨てたの記録がない／外部のフォント配信に通信していた。

## 5. 利用者テストの手順（T9）
1. 空の状態で画面を渡し、「牛乳・卵・鶏肉・パンを買ってきました。アプリに入れてください」とだけ伝える。
2. 渡してから4つ目が入るまでの秒数を測る。説明や手助けはしない。
3. 続けて見本データの画面を5秒見せ、「今日までに使う物は？」と聞く（AC-03）。
4. 終わったら「迷ったところ」を聞いて書き留める。合格は **3人とも 30 秒以内** で、3 に答えられること。
