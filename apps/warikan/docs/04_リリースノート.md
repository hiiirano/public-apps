# その場の割り勘 — リリースノート

## v3.0.0（2026-10-22）
飲み会の会計の場で、幹事がスマホ1台で割り勘を出すアプリとして作り直した。

### できること
- 合計金額を入れて、人数を「＋」「−」か直接入力（2〜30人）
- 1人ずつ「おごり ×0」「少なめ ×0.8」「ふつう ×1」「多め ×1.2」、または金額を指定
- 少なめ・多めの割合を 0.1 刻みで変更
- 集める単位（1円〜千円）と、端数を多めに集めるか少なめに集めるか
- 幹事のおつり・幹事が足す額・幹事が実際に出す額を表示
- LINE に貼る文をコピー、または共有
- 入力を端末に保存して次回も復元。外した人は「元に戻す」で戻せる
- 一度開けばオフラインでも使える。ホーム画面に追加できる

### 前の版（v2）から変わったこと
- PayPay などの支払い方法の切り替えをなくし、現金で集める前提にした
- 倍率の初期値を 0.7 / 1.3 から 0.8 / 1.2 に変更し、ボタンに倍率を表示
- 顔の絵を12種類にし、作者が用意した手描き風の絵に差し替え
- 外部のフォント配信をやめ、通信をしないようにした（CSP で外部への接続を禁止）
- 保存形式を v3 にした。v2 の保存内容は読み込まない（初期状態で始まる）

### 既知の問題・制限
- 名前の漢字など、同梱フォントにない文字は端末のフォントで表示される
- アプリを更新しても、すでに開いたことのある端末では、次に開いたときに新しい版になる（オフライン対応のため）
- 実機（iPhone・Android）での確認と、利用者テストは未実施（テスト計画書 §4・§5）
