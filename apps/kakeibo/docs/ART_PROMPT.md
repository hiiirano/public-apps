## ChatGPT に渡すプロンプト

```
家計簿アプリで使う小さな絵を、1枚のシートにまとめて描いてください。

画風:
- 文房具・手帳になじむ、インクの線画に淡い水彩で色をのせたイラスト
- 線は紺色（#1f2b4d）の細めのペン線。色は生成り・くすんだ朱・苔色・からし色・薄い藍の落ち着いた色だけ
- 影は付けない。立体感はごく控えめ。かわいすぎず、大人向けの上品さ
- どの絵も同じ大きさ・同じ線の太さ・同じ明るさにそろえる
- 文字・数字・ロゴは描かない

並べ方:
- 背景は無地の白（#ffffff）。模様・影・枠なし
- 4列×3行で、絵どうしの間を十分に空ける（切り出しやすいように）
- 1つの絵は正方形の中に収め、まわりに余白を1割ほど残す

描くもの（左上から順に）:
1. おにぎり（海苔つき）
2. 湯気の立つどんぶりと箸
3. トイレットペーパーと洗剤のボトル
4. 小さな一軒家（窓に明かり）
5. 正面から見た電車
6. 本と絵の具のパレット
7. リボンのかかった贈り物の箱
8. 薬のカプセルとばんそうこう
9. 段ボール箱
10. 紺の布表紙の家計簿ノート（閉じた状態、しおりひも付き）
11. 開いたノートと鉛筆（罫線が見える）
12. （空き）
```

## 切り出しのしかた
1. シートを保存し、1つずつ正方形に切り出す。
2. 白い背景を透明にする（例: `magick in.png -fuzz 6% -transparent white out.png`）。
3. 上の表の大きさに縮め、webp にする（例: `cwebp -q 90 -resize 160 160 out.png -o cat-food.webp`）。
4. ライトとダークの両方で、線が見えるか確かめる（ダークの地 #192037 で紺の線が沈む場合は、白いふちを2px足す）。
