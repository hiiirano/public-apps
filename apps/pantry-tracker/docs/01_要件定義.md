## 1. 目的
**家の冷蔵庫・冷凍庫・棚に何があって、いつまでに使えばよいかを、絵で一目でわかるようにする。** 使い切った物・捨てた物を記録して、買いすぎに気づけるようにする。

### 1.1 想定する場面
- スーパーから帰って、牛乳・卵・鶏肉・パンを冷蔵庫や棚にしまう。しまいながらボタンを4回押すだけで記録が終わる。
- 夕方、献立を考える前にアプリを開く。「今日まで」の鶏肉と「明日まで」の牛乳が一番上に出ている。鶏肉を使ったら「使った」を押す。
- 月末、「この30日の記録」で、牛乳を2本捨てていたことに気づき、次は小さいサイズを買う。

### 1.2 やらないこと
- 数量の細かい管理（g・ml など）。数は「1つ・2つ」で数える
- 日用品の在庫・買い物リスト（姉妹アプリ「週間献立プランナー」の役目）
- レシートの読み取り・AI による取り込み（v0.1 にあった AI 連携は API キーが要るため削除）
- 家族での共有・同期・通知（端末の中だけで完結する）
- 会員登録・サーバーへのデータ送信

## 2. 利用者
| 利用者 | 特徴 | 求めること |
|---|---|---|
| 家の料理担当（主） | ITに詳しくない。買い物帰りで手がふさがっている。片手で操作 | 文字を打たずに入れられる。何が急ぐか一目でわかる |
| 家族（従） | たまに冷蔵庫の中身を確かめる | 絵と言葉（「今日まで」）で読める |

## 3. 機能要件

### F1 よく買う物をボタンで入れる
- F1-1 よく買う物 32 種（牛乳・卵・鶏肉・パン・ごはん など）を絵のボタンで並べる。押すと1つ入る。
- F1-2 物ごとに、いつもの置き場所（冷蔵庫・冷凍庫・棚）と、期限のめやす（例: 牛乳 7日、鶏肉 2日、アイスは期限なし）を持つ。
- F1-3 最初は 12 種を出し、「ぜんぶ見る」で 32 種。押した回数の多い物から先に並べる。
- F1-4 入れたら「牛乳を冷蔵庫に入れました（期限 10/30（金））」と知らせ、「直す」「元に戻す」を出す。

### F2 ほかの物を入れる・直す
- F2-1 名前（20文字まで）・絵・置き場所・数（1〜99）・期限（日付、または「期限なし」）を入れる。
- F2-2 名前から絵を当てる（例「鶏むね肉」→ 鶏肉の絵）。絵は 32 種から選び直せる。
- F2-3 期限は日付を選ぶほか、「今日」「3日後」「1週間後」「1か月後」「期限なし」のボタンで入れられる。
- F2-4 名前が空なら入れずに理由を出す。

### F3 家の中を絵で見る
- F3-1 冷蔵庫・冷凍庫・棚の絵の中に、食材の絵を並べる。各置き場所の中は期限が近い順。
- F3-2 1つずつ、絵・名前・数（2つ以上なら「×3」）・期限の札を出す。
- F3-3 期限の札は色と言葉で表す。

| 残り日数 | 言葉 | 色 |
|---|---|---|
| 過ぎた | 「2日すぎ」 | 赤（白文字）・枠も赤 |
| 0日 | 「今日まで」 | 濃いオレンジ（白文字）・枠もオレンジ |
| 1日 | 「明日まで」 | 淡いオレンジ |
| 2日 | 「あと2日」 | 淡いオレンジ |
| 3〜6日 | 「あと5日」 | 淡い黄 |
| 7日〜 | 「あと12日」 | 淡い青緑 |
| なし | 「期限なし」 | 灰 |

- F3-4 上部に「今日は 10/23（金）」と、期限切れ・今日まで・2日以内の数を出す。
- F3-5 「そろそろ使う物」に、期限切れ・今日まで・2日以内の物を並べ、その場で「使った」「捨てた」を押せる。

### F4 使い切った・捨てたの記録
- F4-1 「使った（使い切った）」「捨てた」を押すと、1つ分を記録して数を1つ減らす。0 になったら家の中から消す。
- F4-2 「まちがえて入れた」は記録せずに消す。
- F4-3 どの操作も「元に戻す」で1回取り消せる。
- F4-4 「この30日の記録」（今日を含む30日）に、使い切った数・捨てた数・捨てた割合・捨てた物の一覧を出す。
- F4-5 30日で2つ以上捨て、捨てた数が使った数以上の物は「買いすぎかも」として、次の行動（少なめに買う・早めに冷凍）を添えて出す。

### F5 期限の計算
- F5-1 期限は時刻を持たない暦の日付（YYYY-MM-DD）で持つ。「今日」は端末の時差での日付。
- F5-2 日数の差は暦の通し番号の引き算で出す。夏時間の切り替え日、月末、年末、うるう年（2/29、100年・400年の例外）で1日もずれない。
- F5-3 「1か月後」は行き先の月に同じ日がなければ月末にそろえる（1/31 → 2/28、うるう年は 2/29）。
- F5-4 開いたまま日付が変わったら（夜をまたいだ・別のアプリから戻った）、表示を描き直す。

### F6 保存・書き出し・読み込み
- F6-1 入れた物・記録・よく押す物の回数を端末に保存し、次に開いたとき復元する。
- F6-2 「書き出す」で `pantry-YYYY-MM-DD.json` を保存する。「読み込む」で、そのファイルの内容に入れ替える（「元に戻す」付き）。
- F6-3 違うファイル・壊れたファイルは読み込まず、理由を出す。今の内容は変えない。
- F6-4 v0.1 の保存内容（`pantry-tracker.items`）は v2 の形に移しかえる。v0.1 の AI 設定（API キーを含む）は消す。
- F6-5 保存できない環境（プライベートブラウズ等）でも、その場では使える。
- F6-6 何もないときは「見本を入れる」で見本の在庫と記録を入れられる。「すべて消す」で消せる。

### F7 電波がなくても使える
- F7-1 一度開いた端末では、オフラインでも開いて使える（絵も出る）。
- F7-2 ホーム画面に追加でき、アプリのアイコンが出る。

## 4. 非機能要件
| 区分 | 要件 |
|---|---|
| 対応環境 | iOS Safari 16以上、Android Chrome 最新、PC の Chrome / Safari / Edge 最新 |
| 画面幅 | 320px〜1440px で崩れない。主は 390px。PC は左に操作、右に家の中 |
| 速さ | スマホ回線で初回表示 2秒以内、操作の反映 0.1秒以内 |
| 使いやすさ | 押せるものは 44×44px 以上。入力欄・本文の文字は 16px 以上 |
| アクセシビリティ | WCAG 2.2 AA。コントラスト 4.5:1 以上。キーボードだけで全操作可能。色だけに頼らず言葉でも伝える |
| 個人情報 | 入力内容は端末内だけに保存し、外部に送らない。アクセス解析を入れない |
| 安全 | 入力した名前を画面に出すときは必ず無害化する。外部スクリプトを読み込まない。読み込むファイルは形と範囲を検査する |
| 見た目 | 北欧キッチン風（白・淡い青緑・木の色）。ダークモード対応 |

## 5. 受け入れ基準
| No | 確認すること | 合格の条件 |
|---|---|---|
| AC-01 | 初めての人が使える | 説明なしで、場面1.1の1つ目（4品を入れる）を **30秒以内** に終えられる（3人で確認） |
| AC-02 | 期限の計算が正しい | 自動テストで、月末・年末・うるう年・夏時間・時差の例と、ランダム1万件の日付で、差と足し算が一致 |
| AC-03 | 期限が一目でわかる | 見本データの画面を5秒見せて、「今日まで」の物を言える |
| AC-04 | 記録と集計 | 使った・捨てたを押すと、30日の数と割合が正しく変わる。元に戻すで戻る |
| AC-05 | 書き出し・読み込み | 書き出したファイルを読み込むと元どおりになる。違うファイルは読み込まない |
| AC-06 | 端末 | iPhone 実機（Safari）と Android 実機（Chrome）で、全操作ができる |
| AC-07 | オフライン | 機内モードで開いて使える |
| AC-08 | アクセシビリティ | 自動検査（axe）で違反0件。VoiceOver で物の名前と期限が読める |
| AC-09 | 画面 | 320 / 390 / 768 / 1280px、ライト / ダークで崩れ・重なり・はみ出し0件 |
| AC-10 | 個人情報 | 通信を記録し、外部への送信が0件。API キーの入力欄がない |

## 7. 素材
- 食材の絵 32 種とアイコンは、当面 Microsoft Fluent Emoji（MIT）。のちに ChatGPT で同じ画風の絵を作って差し替える（ART_PROMPT.md）。
- 冷蔵庫・冷凍庫・棚は CSS で描く（絵の差し替え時に絵にしてもよい）。
- 操作アイコンは Tabler Icons（MIT）。書体は BIZ UDPゴシック（OFL）。

## 8. 決めてほしいこと（案のまま進めている点）

- 記録の集計を30日とすること
