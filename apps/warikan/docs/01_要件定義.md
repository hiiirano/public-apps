## 1. 目的
飲み会・食事の会計の場で、**幹事がスマホ1台で、30秒以内に、全員が納得する金額を出して伝える**。

### 1.1 想定する場面
- 7人の飲み会、会計 28,600円。上司は多め、学生2人は少なめ、誕生日の人はおごり。幹事がカードで払い、あとで現金を集める。
- 4人の食事、会計 9,870円。均等割りで100円単位にしたい。

### 1.2 やらないこと
- 旅行などで立て替えを続けて記録すること（定番アプリが強いため）
- PayPay などへの送金連携（現金で集める前提。送金額の表示だけなら使える）
- 会員登録・サーバーへのデータ送信

## 2. 利用者
| 利用者 | 特徴 | 求めること |
|---|---|---|
| 幹事（主） | ITに詳しくない。店の会計前で急いでいる。片手操作。酔っていることもある | 迷わず数字を入れられる。押し間違えても戻せる |
| 参加者（従） | LINEで結果を受け取るだけ | 自分がいくら払えばいいか一目で分かる。傾斜の理由が分かる |

## 3. 機能要件

### F1 合計金額
- F1-1 1円〜9,999,999円の整数。スマホでは数字キーボードが開く。
- F1-2 全角数字・カンマ・「円」付きの貼り付けも受け付ける（例「２８,６００円」→ 28600）。
- F1-3 入力中に3桁区切りで表示する。

### F2 人数と名前
- F2-1 人数は2〜30人。初期値4人。
- F2-2 「−」「＋」と、人数の直接入力（「7人で割る」）の両方で変えられる。
- F2-3 名前は任意。空なら「1人目」「2人目」…と表示する。
- F2-4 人ごとに顔の絵を割り当てる。12人までは重複しない。
- F2-5 人を1人ずつ削除できる。削除は1回で取り消せる（「元に戻す」）。

### F3 傾斜（多め・少なめ）
- F3-1 1人ずつ「おごり」「少なめ」「ふつう」「多め」から選ぶ。初期値は全員「ふつう」。
- F3-2 **各ボタンに倍率を表示する**（例「少なめ ×0.8」）。初期倍率は おごり ×0 / 少なめ ×0.8 / ふつう ×1 / 多め ×1.2。
- F3-3 「割合を変える」ボタン（高さ48px以上、文字で明示）から、少なめ・多めの倍率を0.1刻みで変えられる（少なめ 0.1〜0.9、多め 1.1〜3.0）。変えた倍率は次回も使う。
- F3-4 1人ずつ「金額を指定」もできる（例: 上司は10,000円）。指定した人は傾斜の計算から外れる。
- F3-5 全員がおごり、または指定額の合計が会計を超える場合は、計算せずに理由と直し方を表示する。

### F4 端数
- F4-1 集める単位を 1円 / 10円 / 100円 / 500円 / 1,000円 から選ぶ。初期値は100円。
- F4-2 端数の扱いを2つから選ぶ。初期値は「多めに集める」。
  - 多めに集める（切り上げ）: 幹事に「おつり」が出る
  - 少なめに集める（切り捨て）: 幹事が「足す」
- F4-3 「金額を指定」した人は丸めない。

### F5 幹事
- F5-1 幹事を1人選ぶ。初期値は1人目。
- F5-2 幹事は「集める側」として表示し、「みんなから受け取る合計」と「幹事の実質負担」を示す。

### F6 結果
- F6-1 1人ずつ、名前・顔・払う額を大きく表示する。傾斜がある人は「少なめ」などの札を付ける。
- F6-2 「会計」「集める合計」「差額（おつり／不足）」を必ず表示し、**集める合計 − 会計 = 差額** が常に成り立つ。
- F6-3 結果は入力を変えるたびにすぐ更新する（「計算」ボタンを押させない）。
- F6-4 「LINEで送る文をコピー」。スマホで共有機能が使える場合は「共有」も出す。文の例:
  ```
  本日の会計 28,600円（7人）
  ・たなかさん 6,000円（多め）
  ・さくらさん 3,200円（少なめ）
  ・はるとさん 0円（おごり）
  ・ほか4人 各4,100円
  幹事: ひらの ／ おつり 100円
  ```

### F7 保存と再開
- F7-1 人数・名前・傾斜・倍率・単位・端数の扱い・幹事を端末に保存し、次に開いたとき復元する。
- F7-2 「新しい会計」で金額と金額指定だけを消し、メンバーは残す。「メンバーも消す」は別ボタン。
- F7-3 保存できない環境（プライベートブラウズ等）でも、その場の計算はできる。

### F8 電波が弱い店でも使える
- F8-1 一度開いた端末では、オフラインでも開いて計算できる。
- F8-2 ホーム画面に追加でき、アプリのアイコンが表示される。

## 4. 非機能要件
| 区分 | 要件 |
|---|---|
| 対応環境 | iOS Safari 16以上、Android Chrome 最新、PC の Chrome / Safari / Edge 最新 |
| 画面幅 | 320px〜1440px で崩れない。主は 390px |
| 速さ | スマホ回線で初回表示 2秒以内、操作の反映 0.1秒以内 |
| 使いやすさ | 押せるものは 44×44px 以上。入力欄の文字は 16px 以上（iOS の拡大防止）。片手で主な操作が届く |
| アクセシビリティ | WCAG 2.2 AA。文字と背景のコントラスト 4.5:1 以上。キーボードだけで全操作可能。画面読み上げで金額と結果が読める |
| 個人情報 | 入力内容は端末内だけに保存し、外部に送らない。アクセス解析を入れない |
| 安全 | 入力した名前を画面に出すときは必ず無害化する。外部スクリプトを読み込まない |
| 計算の正しさ | すべて整数の円で計算し、小数の誤差を出さない |
| 見た目 | 無人ラインのデザイン（クリーム地・太い線・角丸・丸い書体）。アプリの色はオレンジ系。ダークモード対応 |

## 5. 受け入れ基準（これを満たしたら完成）
| No | 確認すること | 合格の条件 |
|---|---|---|
| AC-01 | 初めての人が使える | 説明なしで、場面1.1の1つ目を **60秒以内** に結果まで出せる（3人で確認） |
| AC-02 | 計算が正しい | 自動テストで、すべての組み合わせで F6-2 の式が成り立つ（ランダム1万件） |
| AC-03 | 傾斜が分かる | 結果とLINE文だけを見て、参加者が自分の倍率を言える |
| AC-04 | 入力の揺れ | 全角数字・カンマ・「円」付き・空欄・0・上限超えで、落ちずに正しく扱う |
| AC-05 | エラー | 全員おごり・指定額超過で、理由と直し方が表示される |
| AC-06 | 端末 | iPhone 実機（Safari）と Android 実機（Chrome）で、全操作ができる |
| AC-07 | オフライン | 機内モードで開いて計算できる |
| AC-08 | アクセシビリティ | 自動検査（axe）で重大な違反0件。VoiceOver で結果が読める |
| AC-09 | 画面 | 320 / 390 / 768 / 1280px、ライト / ダークで崩れ・重なり・はみ出し0件 |
| AC-10 | 個人情報 | 通信を記録し、外部への送信が0件 |
