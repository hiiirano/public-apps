## ChatGPT に渡すプロンプト
```
学習アプリ「暗記カード」で使う小さなイラストを7つ、1枚のシートにまとめて描いてください。

画風: やさしい手描き風の水彩と色鉛筆。輪郭は藍色（#22407a）の細い線。
色は藍・生成り（#f4eedf）・朱（#a8322a）・黄土・若草を中心に、落ち着いた色だけ。
影は薄く、立体感は控えめ。文字は入れない（1 の「大変よくできました」だけ例外）。
背景は無地の白。7つは重ならないように、間をあけて横4つ×縦2段に並べる。各絵は正方形におさまるように。

1. 桜の花の形をしたはんこ。中に縦書きで「大変よくできました」。朱色。
2. 小さな双葉の芽が植木鉢から出ている。
3. きらきらした星が3つ。
4. リングでとじた紙の単語カードの束（白い罫線入りのカード、銀色のリング）。
5. A・B・C の文字が書かれた積み木。
6. 日本列島の地図（北海道から沖縄まで）。若草色。
7. 液体の入った試験管。
```
受け取ったら1つずつ切り出し、背景を透明にして、上の大きさで WebP にする（例: `cwebp -q 86 -alpha_q 90 -resize 256 256 in.png -o reward.webp`）。差し替えたら `public/art/LICENSES.md` の出典を書きかえる。
