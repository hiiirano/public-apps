# 暗記カード — リリースノート

## v2.0.0（2026-10-23）
「Anki の劣化版」ではなく、紙の単語カードを1枚ずつめくって覚えるアプリとして作り直した。

### できること
- カードを大きく1枚ずつ。押すと裏返り、答えると次のカードへめくれる（動きを減らす設定に対応）
- 4つの答え（わからない・むずかしい・わかった・かんたん）。ボタンに次に出る日を表示
- 「わからない」のカードは、同じ回のうちに少しあとでもう一度出る。押しまちがえたら「ひとつ戻す」
- 今日の分が終わると「大変よくできました」のはんこと、つづけた日数
- 表と裏をタブ・カンマ・改行で区切って貼り付け、まとめて作成。入れられない行は行番号で知らせる
- 見本の単語帳: 中学英単語 20 / 都道府県の県庁所在地 47 / 元素記号 1〜20番
- 単語帳ごとに「文字でコピー」。データ全体の書き出し・読み込み（足す / 入れかえる）
- 新しいカードは1日 20 枚まで（5〜50 枚で変更可）
- スペース・1〜4 のキーだけでめくれる。オフラインで使える。ホーム画面に追加できる

### 前の版（v1）から変わったこと
- AI でカードを作る機能と API キーの入力を削除。外部への通信は 0 件（CSP で禁止）
- 間隔の計算を、4つの答えで間隔がはっきり分かれるように変更（v1 は「むずかしい・ふつう・かんたん」で次の日が同じだった）。間隔は最長 10 年
- 空の単語帳が「今日の学習は完了」と出る問題を修正
- 保存形式を v2（`flashcards.v2`）にした。v1 の単語帳とカードは自動で引き継ぐ
- 見本の「四字熟語」をやめ、3つの見本を選んで入れる形に
- 画面の部品をすべて 44px 以上・文字 16px 以上に

### 既知の問題・制限
- 入力したカードの漢字など、同梱フォントにない文字は端末のフォントで表示される
- 絵は仮に Fluent Emoji を使っている。ChatGPT の絵に差し替える予定（ART_PROMPT.md）
- 端末どうしの自動同期はない（書き出し・読み込みで移す）
- アプリを更新しても、すでに開いたことのある端末では次に開いたときに新しい版になる
- 実機（iPhone・Android）での確認と、利用者テストは未実施（テスト計画書 §4・§5）
