# 週間献立プランナー

人数・好み・除外食材から7日分の献立と買い物リストを作る、登録不要の静的アプリ。slug: `meal-planner`。

- 料理141品：和・洋・中の主菜が各31品、副菜が各16品。
- ジャンル未選択時は主菜の同ジャンル週3日まで・連続2日まで。選択時は選んだジャンルのみ。除外条件を満たす候補が足りない場合は明示。
- アレルゲン9品目（卵・乳・小麦・えび・かに・そば・落花生・くるみ・大豆）と苦手食材を除外。加工品は保守的に登録。商品ごとの表示・混入の確認は別途必要。
- 時短20分以内、冷蔵庫の材料優先、大人・子どもの人数換算、買い物の合算・チェック・コピー・端末保存。
- 生成はローカルのデータとルールのみ。外部生成サービスへの通信やキー設定はありません。
- 共通UIを土台に緑系配色。Fluent Emoji FlatとTabler Outlineをローカル配信。出典・MIT全文は `public/art/LICENSES.md`。

```sh
npm install
npm run dev
npm run build
npm test
npm run preview
```

`src/data/recipes.ts` は分量つき料理データ、`src/data/ingredients.ts` は材料名・単位・カテゴリ・アレルゲンの検査用辞書です。追加時は両方を更新し `npm test` を実行してください。テストは独立した材料名ルールでも漏れを検査します。

保存は入力と乱数シードに基づき献立を再生成します。旧保存データも新しい料理データで再計算し、購入チェックをリセットします。料理データ／選定ロジック変更時は保存形式のバージョンを更新してください。

通信なしで献立計算できますが、初回のページ取得は必要です。オフライン再訪を保証するService Workerはありません。
