# 素材の出典

## イラスト
- 作者が ChatGPT（OpenAI の画像生成）で描いた 5×5 のシート（2026-10-28）を、`deploy/tools/cutsheet.py` で切り出して背景を透明にしたもの（各 256px の WebP）。
- アプリのアイコン（../icon-*.png・../apple-touch-icon.png・../favicon.png）は salad.webp を淡い緑の地に置いて作ったもの。
