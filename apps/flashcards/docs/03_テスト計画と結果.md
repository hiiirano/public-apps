### T2 で必ず成り立つこと
- 間隔は 1〜3650 日の整数。4つの答えの順に、間隔は短い → 長い
- 次の日 = 今日 + 間隔（暦日）。覚えやすさは 1.3〜3.0、小数2桁
- わからない: 続けた回数 0・間隔 1・わからない回数 +1。ほか: 続けた回数 +1
- 3回目以降に思い出せたら、間隔は前より必ずのびる（10年で止まる）
- 同じ入力なら同じ結果。結果は保存の検査に必ず通る
- 今日めくるカード: 日が来た復習はすべて入り、先の日のものは入らない。新しいカードは「1日の上限 − 今日すでにめくった新しいカード」まで。復習が先。重ならない。枚数は一覧の表示と一致
- めくっている最中: 「わからない」のカードは必ずもう一度出る。全部わかるまで終わらない
- 貼り付け: できたカードは表・裏とも空でなく前後の空白がない。カード＋問題の行 ≦ 行数。「文字でコピー」の文字は貼り付けでそのまま戻る
- どんな壊れた保存内容でも落ちず、残ったカードはすべて検査に通る

### T3 の項目
初めは見本の案内／見本を入れると「めくる 20枚」／見本のボタンが「開く」に／新しい単語帳の画面へ／空の単語帳は「まだカードがありません」（v1 の「今日の学習は完了」の誤表示を解消）／貼り付けの見込み（4枚・1行は入れられない）／4枚入る／入力の無害化（`<img onerror>` が動かない）／同じカードはとばす／1枚ずつ（空の注意・追加）／直す／消す・元に戻す／めくる前は答えを読み上げない／めくると答えにフォーカス／ボタンに次の日／わからないは残りが減らない／ひとつ戻す／わからないのカードがもう一度出る／おわりの画面とはんこ／答えの数／つづけた日数／スペース・1〜4・Enter・Tab だけで操作／再読み込みで残る／新しいカードは1日20枚・5枚に変更／書き出し（3冊・73枚）／読み込む前に中身を見せる／同じものは足さない／単語帳を消す・元に戻す／名前を変える／文字でコピー／別の端末で入れかえ／つづけた日も戻る／読めないファイルの注意／壊れた保存内容（空で始め、控えを残す）／v1 の引き継ぎ／動きを減らす設定（アニメーションなし・すぐ次へ）／保存できない環境でも使える／ページエラーなし（10 件）

## 3. 見つかった不具合と対応
| No | 内容 | 見つけた検査 | 対応 |
|---|---|---|---|
| B1 | （v1 から）新しい空の単語帳が「今日の学習は完了」と出る | 前回のレビュー | 「まだカードがありません」と貼り付けへの案内に変更 |
| B2 | （v1 から）AI 未設定なのに AI の欄が先に出て、設定の場所の案内も違う | 前回のレビュー | AI 機能と API キー入力を削除。貼り付けと見本で置きかえ |
| B3 | （v1 から）一覧の「開く」「削除」が高さ 27px・文字 12.8px | 前回のレビュー | すべて 44px 以上・16px 以上に。T4 で全画面を検査 |
| B4 | 320px でめくるカードが横にはみ出す（360px）。最小の高さと縦横比で幅が押し広げられていた | T4 | カードの幅を 100% に固定 |
| B5 | 区切りのない1行のあとに「表,裏」の行が来ると、2行が1枚にまとめられ、裏が「表,裏」になる | T3 | 区切りのある行が来たら、前の1行を「裏がありません」として知らせる。単体テストを追加 |
| B6 | おわりの画面で、はんこが押される途中（1.8倍）に 320px で横にはみ出す | T4 | 始まりを 1.5 倍にし、はみ出しを切る |
| B7 | 見出し「めくって覚える、」「今日の分、おわり！」が語の途中で折り返す | T10 | 句ごとに折り返さないようにした |
| B8 | 47枚の単語帳で、カード一覧が長く「この単語帳」の設定が遠い | T10 | 15枚を超えると「のこり ○枚も見る」 |
| B9 | 320px で見本の名前が「元素記 / 号 1〜」と細かく折り返す | T10 | 狭い幅ではボタンを名前の下に全幅で置く |
| B10 | 本文フォント（BIZ UDPゴシック）が画面の文字に絞っても 2書体で 270KB | ビルドの出力 | Zen Kaku Gothic New に変更（2書体で 140KB） |

## 5. 利用者テストの手順（T9）
1. 画面を渡し、「見本の英単語を入れて、5枚めくってください」とだけ伝える。おわりまでの秒数を測る。
2. 次に、エクセル（またはメモ）の「表・裏」2列の10行を渡し、「これで単語帳を作ってください」と伝える。
3. 終わったら「迷ったところ」「めくるのは気持ちよかったか」を聞く。
4. 合格は 3人とも 1 が 60 秒以内、2 ができる（要件 AC-01・AC-02）。
