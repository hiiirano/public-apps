画面は3つ。アドレスの `#` で切り替え、ブラウザの「戻る」が使える。

| 画面 | アドレス | 中身 |
|---|---|---|
| 一覧 | `#/` | 今日の分・わたしの単語帳・見本・データ |
| 単語帳 | `#/deck/<id>` | めくる・まとめて入れる・1枚ずつ・カード・この単語帳 |
| めくる | `#/study/<id>` | カード・答えのボタン・おわりの画面 |

## 1. 一覧
| 順 | 区画 | スマホ | PC（960px〜） |
|---|---|---|---|
| 0 | 上部（「めくって覚える、単語カード。」・リングでとじたカードの絵） | 文と絵を横並び | 同じ |
| 1 | 今日の分 | ↓ | 左上 |
| 2 | 見本の単語帳 | 単語帳が0冊のときは「今日の分」のすぐ下、あるときは単語帳の下 | 右上 |
| 3 | わたしの単語帳（カード型のタイル・新しい単語帳を作る） | ↓ | 2段目を全幅、タイルは横に並ぶ |
| 4 | データの書き出し・読み込み、1日の新しいカードの数 | ↓ | 3段目を全幅 |

| 部品 | 仕様 |
|---|---|
| 今日の分 | 0冊:「まず単語帳を1冊入れましょう」。めくる分あり: 合計枚数（3rem）。なし: きらきらの絵と「今日の分は、ぜんぶ終わりました。また明日。」。1日以上つづけていれば「🌱 ○日つづけています」 |
| 単語帳のタイル | 罫線入りの紙の札。左上にリングの穴。絵・名前・「全○枚・覚えた○枚」・進み具合の帯。押すと単語帳の画面へ。下に「めくる ○枚」（0枚なら「今日はおわり」） |
| 新しい単語帳を作る | 名前の欄（30文字）と「作る」。作ると単語帳の画面へ移る |
| 見本 | 絵・名前・説明・枚数と「入れる」（入れたあとは「開く」） |
| データ | 「書き出す」（0冊のときは押せない）、「読み込む」。ファイルを選ぶと「単語帳 ○冊・カード ○枚が入っています」と「今のデータに足す」「今のデータと入れかえる」「やめる」 |
| 新しいカードは1日に | 5 / 10 / 20 / 30 / 50 枚まで（初期値 20） |

## 2. 単語帳
| 区画 | 仕様 |
|---|---|
| 上部 | 「← 単語帳の一覧」、絵、名前（h1）、「全○枚・覚えた○枚」 |
| めくる | カード0枚: 「まだカードがありません」。今日の分あり: 幅いっぱいの「めくる（○枚）」と「復習 ○枚・新しいカード ○枚」。なし: 「今日の分は終わりました。次はあした ○枚です。」 |
| まとめて入れる | 書き方の説明と例。貼り付け欄。入力のたびに「○枚 作れます」、最初の3枚（表 → 裏）、入れられない行（最大5行、行番号と理由）、「○枚を入れる」「消す」 |
| 1枚ずつ入れる | 表（問題）・裏（答え）・「1枚入れる」。空なら「表を入れてください。」 |
| カード | 表・裏・状態（まだ / 今日 / 次はあした など）・直す・消す。15枚を超えると「のこり ○枚も見る」。直すとその行が入力欄になる |
| この単語帳 | 名前を変える、「文字でコピー」、「この単語帳を消す」（元に戻すあり） |

PC では「まとめて入れる・1枚ずつ」を左、「カード・この単語帳」を右に置く。

## 3. めくる
| 部品 | 仕様 |
|---|---|
| 上部 | 「× やめる」・単語帳の名前・「ひとつ戻す」（答えたあとだけ） |
| のこり | 「のこり ○枚」と進み具合の帯 |
| カード | 5:3.2 の横長の紙。左に赤い縦線と穴、横に青い罫線。表には「新しい / 復習」の札。文字の大きさは長さで3段階。下に重なったカードが見える（2枚以上のとき） |
| めくる前 | 「めくって答えを見る」（60px）。カードを押してもよい |
| めくったあと | カードが横に裏返り、裏に小さく表・大きく答え。答えにフォーカスを移す。「思い出せましたか？」と4つのボタン（スマホ 2×2、600px〜 横に4つ）。ボタンの色: わからない=朱、むずかしい=黄土、わかった=藍、かんたん=緑 |
| 答えたあと | わからない: カードが右下へ。ほか: 左上へめくれて飛ぶ（0.32秒）。次のカードが下から出る |
| キーボード | PC だけ「スペースでめくる・1〜4で答える」を出す |
| おわり | 「大変よくできました」の花のはんこが押される（0.6秒）。「今日の分、おわり！」、「○回めくりました。」、4つの答えの数、つづけた日数、「単語帳の一覧へ」「この単語帳を見る」 |
| 今日の分がない | 「今日めくるカードはありません」 |

動きを減らす設定: すべてのアニメーション・トランジションを止める（裏返しもすぐ切り替わる）。

## 6. 保存する内容
localStorage のキー `flashcards.v2` に `{version:2, decks, cards, days, newPerDay}`。
- 単語帳: id・名前・絵（own/english/japan/element）・見本の id・作った日時
- カード: id・単語帳 id・表・裏・続けた回数・間隔・覚えやすさ・次の日・めくった回数・わからない回数・初めてめくった日・最後にめくった日・作った日時
- id は英数字・`_`・`-` の 60 文字まで。合わない id は読み込み時に振り直す。単語帳は 200 冊・カードは 2 万枚まで（作成・見本・読み込みで確かめ、こえる分は知らせる）。
- 読み込み時に形と範囲を検査。全体の形が違えば空で始め、元の文字は `flashcards.v2.broken` に残す。1冊・1枚ずつ壊れたものだけ除く。
- `flashcards.v2` がなく v1 のキー（`flashcards.decks` / `flashcards.cards`）があれば引き継ぐ。
