# PFC・TDEE計算 — リリースノート

## v2.0.0（2026-10-23）
1日の目標カロリーと PFC を、数字が苦手な人にも分かるように見せるアプリとして作り直した。

### できること
- 性別・年齢・身長・体重・ふだんの動き（5段階）・目的（やせたい／いまの体重／ふやしたい）を入れると、すぐに目標カロリーを大きく表示
- PFC の割合をリングで表示し、国の目安（食事摂取基準）と比べて知らせる
- 「1食あたり」「ごはん何杯分」「鶏むね肉何g分」「食パン何枚分」「バター大さじ何杯分」のたとえを絵つきで表示
- 基礎代謝・1日の消費・BMI と、自分の数字を入れた「計算のしかた」
- たんぱく質（g/kg）と脂質（%）を変えられる
- よく食べるもの 14品をワンタップで記録。手入力も可。「あと何kcal」と PFC の棒で表示
- 記録の削除・元に戻す、日付の切り替え、書き出しと読み込み
- 一度開けばオフラインでも使える。ホーム画面に追加できる

### 前の版（v0.1）から変わったこと
- 外部 AI による食事の推定と API キーの入力をなくした（保存されていたキーは消す）
- 入力中に欄から外れる・身長が 100 に変わる不具合を直した
- 文字を大きくし（本文 18px）、白地に緑の配色・絵・リングで見た目を一新
- 目標の下限を基礎代謝にした。たんぱく質の初期値を 2.0g/kg から 1.5g/kg に変更
- 年齢・身長・体重の範囲を 18〜100歳・120〜230cm・30〜250kg に変更
- 保存形式を v2（`macro-planner.v2`）にした。前の版の体の情報と記録は引き継ぐ
- 外部のフォント・通信を使わない（CSP で外部への接続を禁止）

### 既知の問題・制限
- 食べ物の名前の漢字など、同梱フォントにない文字は端末のフォントで表示される
- よく食べるものの値は成分表をもとにした目安で、商品や調理で変わる
- 50歳以上のたんぱく質の国の目安（下限 14〜15%）は区別していない（要件 §9）
- アプリを更新しても、すでに開いたことのある端末では、次に開いたときに新しい版になる（オフライン対応のため）
- 絵は仮に Microsoft Fluent Emoji を使用（`ART_PROMPT.md` で差し替え予定）
- 実機（iPhone・Android）での確認と、利用者テストは未実施（テスト計画書 §4・§5）
