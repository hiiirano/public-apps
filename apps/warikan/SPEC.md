# warikan v2 仕様

用途は継続的な立替管理ではなく、その場の飲み会・食事の会計。
初期人数4人、先頭が幹事。任意の名前と順番に割り当てる4種類の人物イラスト。

## 計算

1. 固定額の合計を会計から引く（残額の下限0）。
2. 固定額のない人に残額を比率配分し、指定単位へ切り上げ。
3. 固定額はそのまま採用。傾斜ボタンを押すと固定額は解除。
4. 全員0負担となる設定はエラー。
5. 集める額（幹事分含む）−会計が差額。正は幹事のおつり、負は追加負担、0も表示。
6. 幹事が他の人から受け取る額＝集める額−幹事の予定負担。
7. 幹事の実質負担＝会計−他の人から受け取る額。負値は受け取り超過。

支払い方法を選ぶたび、現金は100円、PayPayなどは1円へ設定。単位は手動変更できる。
会計・人数・名前・幹事・傾斜・固定額・比率・支払い方法・単位を新規localStorageキーへ保存。
新しい会計は合計のみ空欄に戻す。旧版のグループ・共有URL・LLMは廃止。
