## ChatGPT に渡すプロンプト
```
夏の街歩きアプリ「日陰MAP」用のイラストを、1枚のシートにまとめて描いてください。

画風: やさしい手描き風のフラットイラスト。太めのやわらかい輪郭線、丸みのある形、影は1段だけ。
色: 白・水色（#2f97cf 付近）・木陰の緑（#22704a 付近）を基調に、日差しだけオレンジ（#ef8a17 付近）。
背景: 無地の白。各イラストの間は十分にあけ、重ねない。文字は入れない。

描くもの（7点、左上から順に横に並べる）:
1. 砂の上に立つビーチパラソル（白と水色のしま。足もとに涼しい影）
2. こんもりした広葉樹（木陰の緑。足もとに丸い影）
3. 太陽（オレンジ。やわらかい光の線）
4. 東京都庁のような、2本の塔がある大きな庁舎（灰色と水色。正面から）
5. 鉄道の駅（屋根のあるホームと電車の正面。水色）
6. 区役所のようなふつうの役所の建物（四角い中層ビル、正面に旗）
7. 地下鉄の入口（階段が地下へ続く入口と、地下鉄のマーク風の丸。特定の会社のロゴは描かない）

小さく表示しても形が分かるよう、細かい模様は入れないでください。
```
