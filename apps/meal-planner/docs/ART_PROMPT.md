## 3. 受け取った後の作業
1. シートを1マスずつ切り出し、背景の白を透明にする。
2. 256×256 に縮小し、WebP（品質 82）で保存する（例: `cwebp -q 82 -alpha_q 90 in.png -o curry-rice.webp`）。
3. `public/art/` の同じ名前のファイルを置き換え、`npm test`（絵のファイルの有無を検査）と `npm run test:e2e` を実行して、スクリーンショットで見た目を確かめる。
4. `public/art/LICENSES.md` の出典を「ChatGPT（OpenAI）で作成」に書き換える。Fluent Emoji を1点も使わなくなったら、MIT の全文は消してよい。
