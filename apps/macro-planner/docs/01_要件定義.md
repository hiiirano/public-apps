## 1. 目的
体のこと（性別・年齢・身長・体重・ふだんの動き・目的）を入れるだけで、**1日の目標カロリーと、たんぱく質・脂質・炭水化物（PFC）の量**を出す。数字が苦手な人にも「ごはん何杯分」のたとえで伝え、食べたものを記録して残りが分かるようにする。

### 1.1 想定する場面
- 30歳の女性（158cm・52kg、通勤で歩く程度）が「いまの体重をたもつには、1日どれくらい食べればいい？」と知りたい。→ 1,645kcal、ごはん約7杯分と分かる。
- やせたい人が、朝ごはん（ごはん・卵・牛乳）を押して記録し、「あと何kcal食べられるか」を見る。
- 筋トレをしている人が、たんぱく質を体重1kgあたり 2.0g に変えて、PFC の割合を確かめる。

### 1.2 やらないこと
- 食品データベースの検索・バーコード読み取り（定番アプリが強いため。よく食べる14品と手入力で補う）
- 体重の記録・グラフ
- 外部の AI（LLM）による食事の推定。前の版にあった API キーの入力はなくした
- 医療・栄養指導（病気・妊娠中・成長期の人向けの計算はしない）
- 会員登録・サーバーへのデータ送信

## 2. 利用者
| 利用者 | 特徴 | 求めること |
|---|---|---|
| 健康が気になる大人（主） | ITや栄養の言葉に詳しくない。スマホで見る | 入れる項目が少ない。数字の意味が分かる。文字が大きい |
| 体づくりをしている人（従） | PFC を知っている | 割合を自分で変えられる。式が分かる |

## 3. 機能要件

### F1 体のことを入れる
- F1-1 性別（女性・男性）。初期値はなし（選ぶまで計算しない）。
- F1-2 年齢 18〜100歳（整数）、身長 120〜230cm、体重 30〜250kg（小数第1位まで）。初期値はなし。
- F1-3 全角数字・単位つき（「１５８」「52kg」「30歳」）も読む。欄を離れると半角の数字に整える。
- F1-4 範囲外・数字以外は欄の下に理由を出し、結果は直前の正しい値のまま。
- F1-5 ふだんの動きを5段階から絵つきで選ぶ。初期値「すこし動く」。
- F1-6 目的を「やせたい」「いまの体重」「ふやしたい」から絵つきで選ぶ。初期値「いまの体重」。
- F1-7 「PFC の割合を変える」（閉じた状態）で、たんぱく質（体重1kgあたり 0.8〜2.5g、初期 1.5g）と脂質（カロリーの 15〜40%、初期 25%）を変えられる。「はじめの値に戻す」付き。
- F1-8 入力のたびにすぐ計算する（計算ボタンはない）。入力中に欄から外れない。
- F1-9 「見本の値で試す」で、30歳・女性・158cm・52kg を入れる。

### F2 1日の目標
- F2-1 目標カロリーを一番大きく表示し、「いまの体重をたもつ量」など目的を言葉で添える。
- F2-2 PFC の割合を円グラフ（リング）で示し、それぞれのグラム・割合（%）・国の目安（%）を並べる。割合は整数で合計 100%。
- F2-3 国の目安から外れたら「脂質が国の目安より多めです」などと知らせる。たんぱく質と脂質だけで目標カロリーを超えるときは、炭水化物を 0g にして直し方を出す。
- F2-4 減らしすぎを防ぐため、やせたいときも目標は基礎代謝を下回らない。引き上げたらその旨を出す。
- F2-5 「1日の食事の目安」: 1食あたりの kcal、ごはん（茶碗）何杯分、鶏むね肉何g分（卵何個分）、食パン何枚分、バター大さじ何杯分を、絵つきで出す。
- F2-6 基礎代謝・1日の消費・BMI（区分つき）と、BMI 22 になる体重を出す。
- F2-7 「計算のしかた」を開くと、その人の数字を入れた式を見られる。

### F3 食べたものの記録
- F3-1 日付を選んで記録する。初期値は今日。「今日」ボタンで戻る。
- F3-2 よく食べるもの 14品を絵つきで並べ、押すと1つ分を記録する（§6）。
- F3-3 「そのほかの食べ物を入れる」で、名前（30文字まで）・カロリー・PFC を入れる。カロリーが空なら PFC から計算する。全部空・数字以外・上限超え（5,000kcal、500g）は理由を出す。
- F3-4 その日の合計と目標を、カロリーと PFC の棒で示し、「あと ○kcal 食べられます」／「目標より ○kcal 多く食べています」と出す。目標がないときは合計だけ。
- F3-5 記録は1件ずつ消せる。記録・削除は「元に戻す」で1回取り消せる。

### F4 保存とバックアップ
- F4-1 体のことと記録を端末に保存し、次に開いたとき復元する。記録は新しい順に最大 3,000件。
- F4-2 「記録を書き出す」で JSON ファイルに保存、「書き出した記録を読み込む」で戻す。ほかのファイルは読まない。
- F4-3 「すべて消す」は「元に戻す」付き。
- F4-4 前の版（v0.1）の保存内容から、性別・年齢・身長・体重・動き・目的と記録を引き継ぐ。前の版の API キーは読まずに消す。
- F4-5 保存できない環境（プライベートブラウズ等）でも計算と記録はできる。その旨を出す。

### F5 電波がなくても使える
- F5-1 一度開いた端末では、オフラインでも開いて使える。
- F5-2 ホーム画面に追加できる。

## 5. 計算のきまり（根拠）

| 段階 | 式 | 根拠・理由 |
|---|---|---|
| 基礎代謝（BMR） | 男性 10×体重kg + 6.25×身長cm − 5×年齢 + 5／女性 同じ − 161 | Mifflin MD, St Jeor ST ほか（1990）"A new predictive equation for resting energy expenditure in healthy individuals", *Am J Clin Nutr* 51(2):241-247。健康な成人で広く使われ、ハリス・ベネディクト式より誤差が小さいとされる |
| 1日の消費（TDEE） | 基礎代謝 × 活動係数 | 係数は 1.2（ほとんど動かない）/ 1.375（すこし）/ 1.55（ふつう）/ 1.725（よく）/ 1.9（とてもよく）。運動生理学の教科書・多くの計算サービスで使われる一般的な値 |
| 目標カロリー | 1日の消費 × (1 − 0.20)／× 1／× (1 + 0.10)。整数に丸める | 減量は 20% 減（無理のない範囲とされる 1 日 300〜500kcal 程度の不足に当たる）、増量は脂肪をつけすぎない 10% 増 |
| 下限 | やせたいときも 基礎代謝 を下回らない | 「ほとんど動かない」×「やせたい」では 1.2×0.8=0.96 で基礎代謝を下回るため。下回る場合は基礎代謝に引き上げ、その旨を表示 |
| たんぱく質 | 体重 × 1.5g（0.8〜2.5g で変更可）。整数に丸める | 0.8g は推奨量に近い下限、2.5g は運動する人向けの上限。1.5g は見本の人で 19%（国の目安 13〜20% の中） |
| 脂質 | 目標カロリー × 25% ÷ 9（15〜40% で変更可）。整数に丸める | 国の目安 20〜30% の中央 |
| 炭水化物 | （目標カロリー − たんぱく質×4 − 脂質×9）÷ 4。0 未満にしない | 残りを炭水化物に。PFC の kcal 合計は目標と ±2kcal 以内（丸めのみ） |
| 1g あたり | たんぱく質 4、脂質 9、炭水化物 4 kcal | アトウォーター係数 |
| 国の目安 | たんぱく質 13〜20%、脂質 20〜30%、炭水化物 50〜65% | 厚生労働省「日本人の食事摂取基準（2020年版／2025年版）」のエネルギー産生栄養素バランス（目標量、18〜49歳）。50歳以上はたんぱく質の下限が 14〜15% だが、本アプリは 13% で表示する（§9） |
| PFC の割合（%） | 各 kcal ÷ 合計 × 100 を整数にし、端数は大きい順に配る | 合計がいつもちょうど 100% になるように |
| BMI | 体重 ÷ 身長(m)² を小数第1位に。区分は 18.5 / 25 / 30 / 35 / 40 で区切る | 日本肥満学会の判定基準 |

### 5.1 たとえ（言い換え）に使う値
日本食品標準成分表（八訂）の値をもとに、1つ分に直した目安。0.5 きざみ（鶏むね肉は 10g きざみ、1食あたりは 10kcal きざみ）で表示する。

| たとえ | 1つ分 | 使う値 |
|---|---|---|
| ごはん | 茶碗1杯 150g | 234kcal（精白米ごはん 156kcal/100g） |
| 食パン | 6枚切り1枚 60g | 炭水化物 27.8g |
| 鶏むね肉 | 皮なし 100g | たんぱく質 23.3g |
| 卵 | 1個 50g | たんぱく質 6.1g |
| バター | 大さじ1 12g | 脂質 9.7g |
| 1食あたり | 目標 ÷ 3 | — |

## 7. 受け入れ基準（これを満たしたら完成）
