## v2.0.0（2026-10-23）
新宿駅のまわりで「日陰の道」と「近い道」を一目でくらべるアプリとして作り直した。

### できること
- 出発と到着を5か所（東京都庁・新宿駅西口・新宿駅東口・新宿区役所・新宿三丁目駅）から選ぶ。入れかえもできる
- 「日陰の道」と「近い道」を並べ、日なたの時間・歩く時間・日陰の割合と、道の帯（日陰／日なた）でくらべる
- 手描きの絵地図で、選んだ道（日なたの区間には太陽の印）ともう1つの道を見る
- 区間ごとの歩き方（地下・屋根の下・地上）と、開いている時間の注意を見る
- 「データについて」で、日陰・日なたの決め方、季節・時刻を考えていないこと、区間ごとの根拠と出典を見る
- 選んだ場所を端末に保存して次回も復元。一度開けばオフラインでも使える。ホーム画面に追加できる

### 前の版（v0.1）から変わったこと
- 見た目を夏の涼しさ（白・水色・木陰の緑）に変え、絵（Fluent Emoji）と手描きの絵地図にした
- 比べる数を「屋内・屋根あり率」から「日なたの時間（分）」中心に変えた
- 「目安です」の帯を常に出し、データの範囲と限界を画面と要件定義に書いた
- 区間ごとに根拠（どの資料で地下・屋根と判断したか）を持たせ、画面で見られるようにした
- 駅の東西自由通路を「地下」から「屋根の下」に直した。距離を 10m 単位にそろえた（サブナード–15B出口 145→150m、15B出口–区役所 45→50m）
- 日陰の割合を四捨五入から切り捨てに変えた（日なたが少しでもあれば 100% と出さない）
- 保存を URL の `#` から端末の保存（localStorage）に変えた。前の版の URL で開いても読める
- 外部のフォントを使わず、画面の文字だけに絞ったフォントを同梱。公開版は CSP で外部への通信を禁止
- 道さがしのテストを、ランダムな街 3,000 個の性質テストに広げた

### 既知の問題・制限
- 建物・街路樹の影、季節・時刻、天気は考えていない。地上の道はすべて日なたとして数える
- 距離は公式の地図から読んだ概算で、現地で測っていない（要件定義 §3.1 の D1〜D8 が未確認）
- 地下街・駅の通路が閉まる時間は反映していない
- 絵は仮の Fluent Emoji。ART_PROMPT.md の絵に差し替える予定
- アプリを更新しても、すでに開いたことのある端末では次に開いたときに新しい版になる（オフライン対応のため）
- 実機（iPhone・Android）での確認と、利用者テストは未実施（テスト計画書 §4・§5）
