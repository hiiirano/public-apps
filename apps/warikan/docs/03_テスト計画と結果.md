### T2 で必ず成り立つこと
- 1人ずつの額はすべて 0 以上の整数
- 指定額の人は指定額のまま。おごりの人は 0
- 傾斜の人の額は単位の倍数で、本来の額（残額 × 自分の倍率 ÷ 倍率の合計）に対し、切り上げなら 本来 ≦ 額 < 本来 + 単位、切り捨てなら 本来 − 単位 < 額 ≦ 本来
- 倍率が大きい人の額は、倍率が小さい人の額を下回らない
- 集める合計 − 会計 = 差額。受け取る額 + 幹事の分 = 集める合計。幹事が実際に出す額 = 会計 − 受け取る額
- 差額は、切り上げなら 0 以上・単位 × 人数 未満、切り捨てなら 0 以下・単位 × 人数 未満
- エラーになるのは「指定額の合計が会計を超える」「残りがあるのに払う人がいない」場合だけ

## 3. 見つかった不具合と対応

| No | 内容 | 見つけた検査 | 対応 |
|---|---|---|---|
| B1 | 390px 以下で1人ずつの札が横にはみ出す（405px） | T4 | 札の列幅を `minmax(0, 1fr)` にして収めた |
| B2 | 幹事の札（淡いオレンジ）の上で「金額を指定」の文字のコントラストが不足 | T5 | 文字色を #9a3a14 に変更 |
| B3 | ダークで上部の札（黄）の文字のコントラストが不足 | T5 | ダーク用の文字色を用意 |
| B4 | 画面下の帯の裏に、フォーカスやタップしたい部品が隠れる（WCAG 2.2「フォーカスが隠れない」） | T3（テストが帯の上をクリックして失敗） | 画面全体に下 110px のスクロール余白を設定 |
| B5 | 結果が端数の設定の下にあり遠い。1人分の札が縦に長い | T10 | 並びを 金額→人数→結果→端数 に変更。幹事と金額指定を1行にまとめた |
| B6 | 「1,000円」が折り返す | T10 | 「千円」と表記 |
| B7 | フォント読み込みで CSS が 186KB（gzip）になり初回表示 2 秒の目標を満たせない | ビルドの出力 | 画面の文字だけに絞ったフォントを作って同梱（CSS 3KB、フォント計 136KB） |

## 5. 利用者テストの手順（T9）
1. 相手に画面を渡し、「7人で 28,600円。たなかさんは多め、学生2人は少なめ、はるとさんはおごり。あなたが幹事。LINEに送る文まで作ってください」とだけ伝える。
2. 画面を渡してからコピーのお知らせが出るまでの秒数を測る。説明や手助けはしない。
3. 終わったら「迷ったところ」を聞いて書き留める。
4. 合格は **3人とも 60 秒以内**（要件 AC-01）。
