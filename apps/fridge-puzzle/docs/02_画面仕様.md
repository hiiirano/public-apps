## 2. 区画ごとの部品

### パズル
| 部品 | 仕様 |
|---|---|
| 成績の帯 | 3 つの箱。「STAGE 1/3」「手数 0（目標 3）」「TIME 0:00」（0.25 秒ごとに更新）。数字はドット文字 |
| 冷蔵庫 | ミント色の本体・「HIETA」の札・ランプ。中にマス（3×3／3×4／4×4）。マスは正方形・最小 44px（320px 幅の 4 列で約 56px） |
| マス | 食べ物の絵だけ（名前は読み上げのみ）。選ぶと黄色く浮いて絵が揺れる。そろった段はミント色。入れかえると絵が相手の位置から飛んでくる |
| 指（ヒント） | 指の絵が 1 つ目→2 つ目を押す動きを 2.6 秒で繰り返す。2 マスにピンクの点線と「1」「2」の印。1 つ目を押した後は 2 つ目だけを押す動き |
| STAGE の札 | 面の始めに「STAGE n」が 1.1 秒出て消える（押す邪魔をしない） |
| GOAL | 小さな冷蔵庫に、段ごとに同じ物が並んだ完成図（最短になる並び）＋「1段に同じ物」 |
| 操作の絵 | 入れかえの矢印＋「2つ押すと入れかわる」 |
| ヒント | 押すと指が次の最短の 1 手を見せる |

### 持ち主当て
| 部品 | 仕様 |
|---|---|
| 問いの札 | ピンク地・はてなの絵・「で、この冷蔵庫の持ち主は誰？」。大きく叩きつけるように出る |
| 冷蔵庫 | 棚 4 段に、遊んだ食べ物を 2 つずつ＋おまけ 2 つを少し傾けて詰める。読み上げは「冷蔵庫の中身: …」 |
| 候補 | 番号・人物の絵・右下の丸に持ち物・名前。読み上げは「1. マッチョなお兄さん（プロテインを持っている）」 |
| 一言 | 点線の札「持ってる物が ヒントかも…？」 |

### 結果
| 部品 | 仕様 |
|---|---|
| 発表 | 「正解！」または「正解は…」、回る黄色の星形の上に正解の人（持ち物つき）が落ちてくる。名前 |
| ひとこと | 「いや知らんわ！」など（大きいピンク文字）。結果に来たらここに読み上げの焦点を移す |
| 種明かし | 4 人の持ち物の絵に × 。「ちなみに、手に持ってた物は 正解と一切関係ありません。」 |
| 答えくらべ | 「正解」「あなた」「送った人」（共有で来たときだけ）。当たりはミント色 |
| 成績 | ★合計（9 つ中）・合計手数（最短）・合計タイム。共有で来たときは送った人との勝ち負け。2 回目以降は自己ベストか「自己ベスト更新！」 |
| ボタン | 「友だちにやらせる」（黄）、「ちがう冷蔵庫で もう1回」 |
| 共有のお知らせ | 「送る画面を開きました」「リンクをコピーしました。LINEなどに貼ってね」。失敗時はリンクの欄を出す |

## 3. 状態
| 状態 | 表示 |
|---|---|
| ふつうに開いた | 新しい問題の 1 面目。指が出ている |
| 共有リンクで開いた | 「友だちから届いた問題です」。同じ問題 |
| 壊れた・前の版のリンク | 黄色の札「リンクが読めなかったので、新しい問題にしました。」。URL の # 以降は消す |
| 保存できない | 何も出さずに遊べる（記録だけ残らない） |
| 動きを減らす設定 | 指・揺れ・回転・飛ぶ動きを止める。指は 1 つ目（または 2 つ目）の上に止まって出る。待ち時間は 0.5 秒まで |
| オフライン | 一度開いていれば同じように遊べる |

## 5. 保存する内容
キー `hiehie-fridge.v2`（localStorage）。

| 項目 | 形 |
|---|---|
| plays | 遊んだ回数（0〜1,000,000 の整数） |
| best | null か {stars: 1〜9, moves: 1〜999, secs: 0〜35999} |

読み込み時に形と範囲を検査し、壊れていれば初期状態（plays 0・best null）。

## 6. 共有リンク
`#play=hiehie-fridge&v=2&seed=<8〜24字の英小文字と数字>&pick=<0〜3>&m=<1〜999>&t=<0〜5999>`

- seed から 3 面・冷蔵庫の中身・候補・持ち物・正解を毎回同じに作る。正解そのものは入れない。
- m・t は送った人の合計手数とタイム（なくてもよい。片方だけは壊れている扱い）。
