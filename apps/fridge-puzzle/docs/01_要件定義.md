## 1. 目的
ゲームコーナー「しょうもなゲーム」の 1 本目。**ちゃんと遊べる短いパズルを 3 面クリアした直後に、ゲーム側が後出しで台無しにする**笑いを、説明を読まずに 1〜2 分で味わってもらい、友だちに送りたくさせる。

ゲームなので、要件・受け入れ基準は「遊びとして成立するか」「説明なしで遊べるか」を中心に置く。

### 1.1 想定する場面
- 休み時間にスマホで開き、1 分半ほどでパズル 3 面を解く。突然「この冷蔵庫の持ち主は誰？」と聞かれ、手に持っている物を手がかりに選ぶ。「持ち物は正解と一切関係ありません」で笑い、LINE で友だちに送る。
- 送られた友だちは、同じ冷蔵庫・同じ候補・同じ正解で遊び、最後に送った人の答えと手数を比べる。

### 1.2 やらないこと
- 公平な推理（持ち物や中身から論理的に当てられる問題）。正解はわざと根拠なしにする
- ランキング・ログイン・サーバー保存・広告・課金
- 音（静かな場所でも遊べるよう、今回は入れない）

## 2. 利用者
| 利用者 | 特徴 | 求めること |
|---|---|---|
| 遊ぶ人（主） | ゲームに慣れていない人も含む。説明文は読まない | 見ただけで何をすればいいか分かる。すぐ終わる |
| 送られた友だち | リンクから直接開く | 同じ問題で遊べる。送った人と比べられる |

## 3. 機能要件

### F1 説明を読まずに始められる
- F1-1 開くとすぐ 1 面目。タイトル画面・説明画面は挟まない。
- F1-2 1 面目では、**最初の 1 手を指の絵が動いて見せる**（1 つ目のマスを押す → 2 つ目のマスへ移って押す、を繰り返す）。指す 2 マスには「1」「2」の印。
- F1-3 指のとおり 1 つ目を押すと、指は 2 つ目だけを指す。違うマスを押したら指は消える。
- F1-4 2 面目以降は、**10 秒手が止まったら**指が次の 1 手を見せる。「ヒント」ボタンでもすぐ出せる。
- F1-5 文字の案内は最小限（「GOAL 1段に同じ物」の絵と、「2つ押すと入れかわる」）。

### F2 パズル
- F2-1 冷蔵庫のマスを 2 つ押すと中身が入れかわる。同じマスをもう一度押すと選択をやめる。同じ種類どうしは入れかえず、選び直しになる（手数に数えない）。
- F2-2 すべての段が 1 種類ずつになればクリア。どの段にどの種類が来てもよい。
- F2-3 1 回のプレイは 3 面。**3段×3列 → 3段×4列 → 4段×4列** と増え、目標手数（最短手数）も 3 → 4 → 6〜7 手と増える。
- F2-4 画面上部に「STAGE n/3」「手数（目標 n）」「TIME」を出す。
- F2-5 そろった段は色が変わる。面をクリアすると「CLEAR!」・★（最短なら 3、最短+2 手まで 2、それ以上 1）・手数・タイムを 1.7 秒出して次の面へ。3 面目の後は「ALL CLEAR!」。
- F2-6 盤面は毎回ちがう。必ず解ける。最初からそろってはいない。

### F3 冷蔵庫の中身
- F3-1 食べ物は 37 種類。肉・魚・野菜・卵と乳製品・飲み物（ビール・プロテインなど）・作り置き（作り置き・残り物・納豆・カレーなど）・甘い物・果物・その他（なぞのびん・氷・ほにゅうびん）。
- F3-2 1 つの面では、分類も色味も重ならない物を選ぶ（見分けやすさのため）。3 面で同じ物は使わない。甘い物は 1 回に 1 つまで。

### F4 持ち主当て（後出し）
- F4-1 3 面クリアの直後、突然「で、この冷蔵庫の持ち主は誰？」と出す。冷蔵庫の中（遊んだ食べ物＋おまけ 2 つ）を棚に詰めて見せる。
- F4-2 候補は 22 人から毎回 4 人（マッチョなお兄さん・おばあちゃん・忍者・名探偵・ゾンビ・ねこ・宇宙人・吸血鬼・シロクマ・赤ちゃん など）。
- F4-3 候補はそれぞれ何かを手に持つ。4 人で重ならず、7 割は冷蔵庫にある物（いかにも手がかりに見える）。「持ってる物が ヒントかも…？」と添える。
- F4-4 選ぶと 1.2 秒「判定中…」で冷蔵庫が震え、正解の人がはね出てくる。
- F4-5 正解は 4 人から均等に選び、持ち物とは無関係。結果で「ちなみに、手に持ってた物は 正解と一切関係ありません。」と明かし、4 人の持ち物に × を付けて見せる。
- F4-6 ひとこと: 当たり「なんで分かった？」、はずれ「いや知らんわ！」（共有時は 5 通り。§F5-4）。

### F5 共有
- F5-1 「友だちにやらせる」で共有画面（使えない端末ではリンクと文をコピー）。コピーもできなければリンクを画面に出す。
- F5-2 リンクには問題の番号（seed）・自分が選んだ位置・合計手数とタイムだけを入れ、正解は入れない。
- F5-3 受け取った人には「友だちから届いた問題です」と出し、同じ 3 面・同じ候補・同じ正解で遊ばせる。
- F5-4 結果で「正解・あなた・送った人」と、送った人の手数・タイムとの勝ち負けを出す。ひとこと: 二人とも正解／自分だけ／送った人だけ／同じはずれ／別々のはずれ。
- F5-5 **壊れたリンク・前の版のリンク**は、落ちずに新しい問題で始め「リンクが読めなかったので、新しい問題にしました。」と出す。

### F6 記録
- F6-1 遊んだ回数と自己ベスト（★→手数→タイムの順で良い方）を端末に保存し、2 回目以降の結果に出す。
- F6-2 保存できない・壊れている場合も遊べる（記録は初期状態）。

### F7 オフライン
- F7-1 一度開いた端末では、通信なしで開いて遊べる（全部の絵を控えておく）。ホーム画面に追加できる。

## 4. 非機能要件
| 区分 | 要件 |
|---|---|
| 対応環境 | iOS Safari 16 以上、Android Chrome 最新、PC の Chrome / Safari / Edge 最新 |
| 画面幅 | 320px〜1440px で崩れない。主は 390px。PC では冷蔵庫と案内を 2 列に |
| 速さ | 盤面の生成・ヒント計算は 0.1 秒以内（4×4 でも 1 手 30ms 程度） |
| 使いやすさ | 押せるものは 44×44px 以上。文章は 16px 以上。片手で遊べる |
| アクセシビリティ | WCAG 2.2 AA。コントラスト 4.5:1 以上。キーボードだけで遊べる（Tab と矢印キーでマスを移動、Enter で押す）。マスは「2段目 3列目 にんじん」と読み上げる。動きを減らす設定では指は止まった絵になる |
| 個人情報 | 送るのは問題番号と自分の答えと手数だけ。アクセス解析なし。外部への通信 0 件 |
| 見た目 | ゲームコーナー案「D ゲームセンター」（紺 #1b1446・黄 #ffe14d・ミント #7ef0c6・ピンク #ff6b8b、ドット文字）。ダーク時はこの紺、ライト時は淡い紫地 |
| 笑いの品質 | 人種・性別・体型・年齢そのものを笑いにしない。強い点滅・大音量を使わない |

## 5. 受け入れ基準（これを満たしたら完成）
| No | 確認すること | 合格の条件 |
|---|---|---|
| AC-01 | 説明なしで遊べる | 初めての人に画面だけ渡し、**1 面目の最初の 1 手を 15 秒以内**に指のとおり押せる（3 人で確認） |
| AC-02 | 遊びとして成立 | 3 面を 3 分以内に解ける。2〜3 面目で「少し考えた」と言う人がいる |
| AC-03 | 後出しが伝わる | 結果画面を見て「持ち物は関係なかった」と口で言える。笑う・ツッコむ反応がある |
| AC-04 | 必ず解ける | 自動テストで、生成した 900 面すべてが最初はそろっておらず、ヒントどおりに最短手数でクリアできる |
| AC-05 | 最短手数が正しい | 3×3 と 3×4 の全配置で、総当たりの最短手数と一致する |
| AC-06 | 毎回ちがう・偏らない | 盤面・中身・候補が毎回変わる。正解の位置・候補の登場・各マスの種類に偏りがない（統計テスト） |
| AC-07 | 共有 | 共有リンクで同じ問題になり、送った人と比べられる。壊れたリンクで落ちない |
| AC-08 | 端末 | iPhone 実機（Safari）と Android 実機（Chrome）で 1 ラウンド遊べる |
| AC-09 | アクセシビリティ | axe の違反 0 件。キーボードだけで 1 ラウンド遊べる |
| AC-10 | 画面 | 320 / 390 / 768 / 1280px、ライト / ダークで崩れ・重なり・はみ出し 0 件 |
| AC-11 | 通信 | 外部への通信 0 件。オフラインで遊べる |
